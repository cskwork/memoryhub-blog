Array

Data, Index, Continuity

Definition

-A collection of variables of the same data type

Features

-Array is an object.

-Using the array name to reference consecutive variables. /Using index

-Cannot change size.

Queue

OLDEST FIRST

Features

-FIFO (First In First Out)

-PUSH POP

Dequeue

-Can insert and delete from both ends

Stack

RECENCY

-LIFO (Last In First Out)

-PUSH POP PEEK

Linked List

Node, Pointer, Connection

Definition

-It is a data structure for storing data.

-It consists of nodes.

-Nodes have data and pointers.

-Nodes are connected to other nodes.

Features

-Size not fixed, easy to add/delete

-Duplicates allowed

-There are singly, doubly, and circular linked lists.

Binary Tree

A<B, GOTO Child LEFT, LEFT TO RIGHT

-One node has two child nodes
