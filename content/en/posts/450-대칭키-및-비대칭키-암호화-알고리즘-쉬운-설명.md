Encryption is a technology to protect data safely, and there are two main types: **symmetric key encryption** and **asymmetric key encryption**.

---

### **1. Symmetric Key Encryption**

? **"Lock and unlock with the same key"**

? **Concept:**

- Sender and receiver use the **same key (secret key)** to encrypt and decrypt data.
- If the key is exposed, security can be compromised, so it's important to share the key safely.

? **Example:**

- When sending a secret message to a friend, you both decide on the same code (e.g., "1234"), and you encrypt the sentence using it and send it.
- The other person also needs to know the same code to decrypt the original message.

? **Representative Algorithms:**

- **DES (Data Encryption Standard)**: Old method, weak security
- **AES (Advanced Encryption Standard)**: Widely used now, strong security
- **RC4, Blowfish, 3DES** and others.

? **Advantages & Disadvantages:**  
✅ **Fast!** Because it's fast, it's advantageous for encrypting large amounts of data.  
❌ **Difficult key management!** If the key is leaked, there's a big risk of security breach.

---

### **2. Asymmetric Key Encryption**

? **"Lock with a public key, unlock with a secret key"**

? **Concept:**

- Use two keys (public key and private key) to encrypt and decrypt data.
- The **public key** is open to everyone, but the **private key** must be known only to the owner.
- When sending a message, encrypt it with the **recipient's public key**, and the recipient decrypts it with their **private key**.

? **Example:**

- You lock the letter you send me with **my public key**.
- I can only open that letter with **my private key**.

? **Representative Algorithms:**

- **RSA (Rivest-Shamir-Adleman)**: The most famous method
- **ECC (Elliptic Curve Cryptography)**: Provides strong security with shorter keys than RSA
- **Diffie-Hellman**, **DSA (Digital Signature Algorithm)** and others.

? **Advantages & Disadvantages:**  
✅ **Strong security!** Safe communication without key sharing problems.  
❌ **Slow!** Because it requires more computation than symmetric key encryption, it's slower.

---

### **Easy Understanding with Analogies**

? **Symmetric Key Encryption = Same Lock and Key**  
? Think of sharing the same lock and key with a friend. Anyone who has that key can open the door.  
? The problem is that everything is exposed if the key falls into someone else's hands!

? **Asymmetric Key Encryption = Mailbox and Key**  
? Everyone can put letters in your mailbox, but you're the only one with the key (private key), so only you can take them out.  
? Safe, but it takes more time since you have to open multiple locks.

---

### **Where is it Used?**

✅ **Symmetric Key Encryption:**

- File encryption
- Database security
- VPN communication

✅ **Asymmetric Key Encryption:**

- Email security (PGP)
- SSL/TLS (website security)
- Digital signature (electronic contracts, blockchain)
