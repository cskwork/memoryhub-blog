### 1. Summary of Main Model Reviews After Use

- **GPT-5.1 (Thinking / Codex)**
  - Strengths: Strong in research (Deep Research), report/document writing, policy and planning documents. More stable than GPT-5 with improved instruction comprehension and reduced hallucination. ([Tom's Guide](https://www.tomsguide.com/ai/gpt-5-1-is-here-7-prompts-to-test-openais-smarter-more-customizable-chatgpt?utm_source=chatgpt.com "GPT-5.1 is here - 7 prompts to test OpenAI's smarter, more customizable ChatGPT"))
  - Coding: **GPT-5.1-Codex-Max** especially excels in agent-style coding. Shows good results for large-scale repository refactoring, long debugging sessions, and full-agent backend-focused work. ([OpenAI](https://openai.com/index/gpt-5-1-codex-max/?utm_source=chatgpt.com "Building more with GPT-5.1-Codex-Max"))

- **Gemini 3 Pro (+ Nano Banana Pro)**
  - Strengths: Shows highest-level reasoning and multimodal performance by latest benchmarks, strong in frontend, design, web UI generation. Image recognition/generation outstanding, especially high quality for images with embedded text. ([blog.google](https://blog.google/products/gemini/gemini-3/?utm_source=chatgpt.com "A new era of intelligence with Gemini 3"))
  - Weaknesses/Characteristics: Sensitive to prompt style and context; requires relatively detailed prompts to get desired quality. Can produce confident but incorrect answers in unfamiliar domains, requiring validation. Tends to perform very well and not follow user instructions precisely.

- **Claude Sonnet 4.5 / Opus 4.1**
  - Strengths: Paired with Claude Code, "copilot-style" usability in IDE/terminal is excellent, strong in natural language explanation, review, and documentation. Produces best agentic performance in actual development environment separate from benchmarks, and can work interactively with users.
  - Weaknesses/Characteristics: By latest benchmark standards, loses edge against GPT-5.1 and Gemini 3 Pro in reasoning and agent coding domains. Still top-tier overall model though, with strong stability and UX. ([16x Eval](https://eval.16x.engineer/blog/claude-vs-claude-api-vs-claude-code?utm_source=chatgpt.com "Claude, Claude API, and Claude Code: What's the Difference?"))

### 2. Current Coding Tool UX Evaluation (Internal test basis)

- **Usability/UX Order (Developer actual usage basis)**
  1. Claude Code
  2. Codex (GPT-5.1-Codex series)
  3. Gemini CLI

- **Model Intelligence/Performance (Combined benchmark + practical feel)**
  - Complex reasoning/multimodal basis:
    - Gemini 3 Pro ≥ GPT-5.1 series > Claude Sonnet 4.5
  - Agent-style coding basis:
    - GPT-5.1-Codex-Max and Gemini 3 Pro top tier, Sonnet 4.5 stable but relatively losing edge. ([IT Pro](https://www.itpro.com/technology/artificial-intelligence/google-launches-flagship-gemini-3-model-and-google-antigravity-a-new-agentic-ai-development-platform?utm_source=chatgpt.com "Google blows away competition with powerful new Gemini 3 model"))

- **Tool Characteristics**
  - Claude Code:
    - Rich advanced features including sub-agents, commands, hooks, plan mode, sandbox, and strong IDE/terminal integration—feels like "a copilot great for attaching to development environment." ([SDpower](https://blog.sd.idv.tw/en/?utm_source=chatgpt.com "Claude Code Hooks System and Migration Guide - SDpower"))
  - Gemini CLI / Code Assist:
    - Simple to install and start; works well for frontend/design and video work all at once through integration with Google Antigravity, Flow, Whisk, etc. Features being added rapidly. ([IT Pro](https://www.itpro.com/technology/artificial-intelligence/google-launches-flagship-gemini-3-model-and-google-antigravity-a-new-agentic-ai-development-platform?utm_source=chatgpt.com "Google blows away competition with powerful new Gemini 3 model"))
  - Codex (GPT-5.1 Codex series):
    - Can run agent loops for extended periods through automatic context compression, provides consistent experience across CLI, IDE, Cloud. Especially suited for backend/infrastructure and large-scale refactoring. ([OpenAI](https://openai.com/index/gpt-5-1-codex-max/?utm_source=chatgpt.com "Building more with GPT-5.1-Codex-Max"))

### 3. Subscription Scenario Options Summary

#### Option 1. Google AI Ultra 1 account (family sharing) – Company-wide experiment plan

- Configuration
  - Google AI Ultra 1 account + family sharing (max 5 people)
  - Development 2: Gemini CLI, Gemini Code Assist, Antigravity IDE, Jules, etc.
  - Planning 1: Gemini 3 Pro + Deep Research, NotebookLM, Project Mariner
  - Marketing 1: Flow, Whisk, Nano Banana Pro, YouTube Premium
  - Admin 1: Billing/management account

- Advantages
  - 30TB storage, Deep Research, Veo 3, Gemini Agent—multiple departments can experiment with entire Google ecosystem features. ([Google One](https://one.google.com/about/google-ai-plans/?utm_source=chatgpt.com "Google AI Plans with Cloud Storage"))
  - PoC possible at relatively low cost during initial 3-month discount period. ([blog.google](https://blog.google/products/google-one/google-ai-ultra/?utm_source=chatgpt.com "Google announces AI Ultra subscription plan"))

- Cautions/Notes
  - Using personal Google accounts and family structure for company work needs separate review against company security and policy.
  - Separate system from Google Workspace (company Gmail/Drive).

#### Option 2. Claude-focused adoption (Claude Pro/Max 5X Plan basis)

- Example configuration
  - Core development team adopts Claude Pro N seats or Claude Max 5X Plan (max 4-seat account sharing)
  - Deploy Claude Code to all as IDE/terminal copilot
  - Planning and general users use basic Claude web app

- Advantages
  - Excellent Claude Code UX, covers non-dev tasks too including **Skills/MCP**, document analysis, spreadsheet processing. ([16x Eval](https://eval.16x.engineer/blog/claude-vs-claude-api-vs-claude-code?utm_source=chatgpt.com "Claude, Claude API, and Claude Code: What's the Difference?"))
  - Deep Research, Google Workspace/Office 365 integration—high "business assistant" adoption.

- Disadvantages
  - Per-seat cost under official pricing; for 8 people, cost may exceed Google AI Ultra family sharing.
  - Multimodal (image/video generation) needs separate tool pairing. (mcp)

#### Option 3. ChatGPT Business (Codex) – Backend/Research Optimized

- Configuration
  - ChatGPT Business minimum 2+ seats (developer/planner focused) ([OpenAI Help Center](https://help.openai.com/en/articles/11481834-chatgpt-rate-card?utm_source=chatgpt.com "ChatGPT Rate Card (Business, Enterprise/Edu)"))
  - Codex CLI/IDE for all developers with Plus/Pro/Business access ([OpenAI Developers](https://developers.openai.com/codex/models/?utm_source=chatgpt.com "Codex Models"))

- Advantages
  - GPT-5.1(Thinking/Instant) + GPT-5.1-Codex-Max combination:
    - Very strong for "hard coding work": backend, infrastructure, data pipeline. ([Composio](https://composio.dev/blog/kimi-k2-thinking-vs-claude-4-5-sonnet-vs-gpt-5-codex-tested-the-best-models-for-agentic-coding?utm_source=chatgpt.com "GPT-5.1 Codex vs. Claude 4.5 Sonnet vs. Kimi K2 Thinking"))
  - ChatGPT Deep Research is currently most mature level of research agent among commercial offerings. ([WIRED](https://www.wired.com/story/openai-launches-an-agentic-web-based-coding-tool?utm_source=chatgpt.com "OpenAI Launches an Agentic, Web-Based Coding Tool"))
  - Covers multimedia generation too with Sora 2 (video), GPT-series image models. ([OpenAI](https://openai.com/index/sora-2/?utm_source=chatgpt.com "Sora 2 is here"))

- Disadvantages
  - Image/video generation quality varies by domain compared to Nano Banana Pro, Veo 3 series; Google combination may be more attractive for design/marketing use. ([Android Central](https://www.androidcentral.com/apps-software/ai/nano-banana-goes-pro-with-refined-design-consistency-and-accuracy-in-the-gemini-app?utm_source=chatgpt.com "Nano Banana goes Pro with refined design consistency and accuracy in the Gemini app"))

### 4. Final Recommendation Direction (Summary)

- **Development perspective**
  - Backend, infrastructure, large-scale refactoring: **ChatGPT Business - Codex (GPT-5.1-Codex-Max)**
  - Frontend, design, web apps: **Gemini 3 Pro + Gemini CLI (currently only available on Ultra Plan) / Antigravity**
  - **IDE/terminal-based copilot and predictable, stable, well-balanced full-stack coding: Claude Code**

- **Non-development work perspective**
  - Planning, research, reports: GPT-5.1 Deep Research, Claude Deep Research parallel use
  - Marketing/design: Google AI Ultra (or Pro) based Nano Banana Pro, Flow, Whisk

- **Realistic Phase 1 Adoption Proposal**
  - **① Company-wide PoC:** Provide Claude Pro Max 5x account 2 (1 person: 4 accounts) to core 4-8 dev team members.
  - ② Parallel PoC: Google AI Pro or Ultra 1 account (5-person family) or ChatGPT Business (3-month multi-department pilot).
  - ③ After 3 months, re-design based on actual usage, satisfaction, security/policy issues into "formal seat structure (Claude Team - Premium only for Claude Code / ChatGPT Business multi-seat) + Google AI Pro/Ultra as needed"
