When doing web development and working with CSS, sometimes page reloading doesn't reflect your changes no matter how many times you try.

This happens because CSS files are being cached in your browser (the browser saves the CSS file locally to avoid having to fetch it every time). You can simply disable this caching feature.

Just refer to the image below!
