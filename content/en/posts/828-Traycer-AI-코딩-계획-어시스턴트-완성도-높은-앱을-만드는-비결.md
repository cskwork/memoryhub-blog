## 1. Background: Common Problems with AI Coding Tools

Existing AI coding assistants focus on instant code generation. Tools like GitHub Copilot, Cursor, and Windsurf shine at rapid prototyping but show their limits with complex tasks in large codebases. Developers experience:

**✅ Limitations of Existing AI Coding Tools**

- Cryptic code diffs are hard to understand
- Missing edge cases during large refactoring
- No quality verification of AI-generated code
- Difficult to track changes across multiple files

**Related Terms**

- **Codebase**: The complete source code collection of a project
- **Refactoring**: Improving code structure without changing functionality
- **Agent**: An AI program that operates autonomously

---

## 2. Core: Plan-First, Code-Second Strategy

> **Traycer's differentiator is its 'plan-first' approach.**
>
> Before writing code, it generates detailed, executable plans so developers can collaborate with AI at the idea level instead of cryptic code changes.

Traycer intelligently analyzes your task and codebase to generate detailed implementation plans and clearly identify which files to modify and dependencies. Developers can review and adjust the plan before code generation, ensuring the result meets expectations.

**How It Works**

1. **Analyze task** → AI analyzes entire codebase
2. **Generate plan** → Present file-by-file changes and steps
3. **Review and refine** → Developer fine-tunes the plan
4. **Execute code** → Submit plan to Cursor, Claude Code, etc.
5. **Auto-verify** → Scan generated code to prevent errors

## 3. Getting Started: Traycer Tutorial

### ① Installation (VSCode)

Search for "Traycer" in VSCode Extensions Marketplace and install. Click the Extensions icon (Ctrl+Shift+X), search for "Traycer - AI for Software Development", and click Install.

### ② Create Your First Task

Select "New Task" from the sidebar and describe the feature you want to implement in natural language.

**Example Prompt**

> "Add dark mode toggle to the React app. Save user settings in localStorage, and the entire theme should change immediately."

Traycer automatically analyzes your codebase and generates an execution plan with related files, dependencies, and implementation steps.

### ③ Review and Modify Plan

Review the generated plan and refine necessary parts. You can fine-tune file lists, change order, logic, and more.

### ④ Generate Code

Once the plan is complete, send it with a single click to your preferred AI agent (Cursor, Claude Code, Windsurf, etc.). Code generation begins immediately.

### ⑤ Auto-Verify

Traycer scans your codebase to validate all changes, provides correction suggestions to prevent buggy code in production, and identifies bugs, security issues, and performance improvements in real time.
