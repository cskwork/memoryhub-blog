## Overview

This guide introduces how to merge 15 CSV files into a single file. This guide explains the method using a terminal in macOS/Linux environments.

## Situation

- **Target Files**: 15 CSV files starting with `_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111`
- **File Composition**: 1 base file + 14 numbered files (_2.csv ~ _15.csv)
- **Total Size**: Approximately 140MB
- **Total Data**: Over 1.6 million rows

## Step-by-Step Execution

### Step 1: Verify Files

```
# Check list of CSV files
ls -la *연구용*111*.csv

# Verify file count
ls -1 *연구용*111*.csv | wc -l
```

### Step 2: Verify File Order

```
# Generate filenames in correct order
printf '%s\n' _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111.csv _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_{2..15}.csv
```

### Step 3: Copy Base File

```
# Copy first file as merge result file (includes header)
cp "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111.csv" "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv"
```

### Step 4: Sequentially Merge Remaining Files

```
# Merge files 2 through 15, excluding header and adding data only
for i in {2..15}; do 
    echo "Adding file _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_${i}.csv"
    tail -n +2 "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_${i}.csv" >> "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv"
done
```

### Step 5: Verify Results

```
# Verify line count of individual files
echo "Line count of individual files:"
for file in _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111.csv _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_{2..15}.csv; do 
    echo "$file: $(wc -l < "$file")"
done

# Verify line count of merged file
echo "Line count of merged file:"
wc -l "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv"

# Final file info
ls -lh "*merged.csv"
head -2 "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv"
```

## Execution Results

- **Merged File**: `_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv`
- **File Size**: 138MB
- **Total Rows**: 1,605,541 rows (1 header row + 1,605,540 data rows)
- **Verification**: ✅ Matches sum of individual files minus 14 duplicate headers

## Key Points

1. **Order Matters**: Merge files in numeric order of filenames
2. **Header Handling**: Include header only for first file, use `tail -n +2` to exclude header for others
3. **Verification Essential**: Confirm no data loss through row count calculation
4. **Efficiency**: Automate with `for` loop and `tail` command

## Applying to Different Situations

If filenames are different, modify only these parts:

- Base filename pattern
- File number range `{2..15}` → `{2..N}`
- Output filename

Using this method allows you to merge large CSV files efficiently in terms of memory.
