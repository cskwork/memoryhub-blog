## 1. Background - Why Rust Now?

### 🔍 Problems with Existing Languages

| Language | Advantages | Critical Drawbacks |
| --- | --- | --- |
| C/C++ | Fast performance | Memory bugs (70% of security vulnerabilities) |
| Java/C# | Memory safe | GC-induced performance degradation |
| Python | Easy syntax | Slow execution speed |
| **Rust** | **All advantages** | **Learning curve** (solvable!) |

### ✅ What Rust Solves

- **Memory Safety**: All memory errors blocked at compile time
- **Concurrency**: Eliminates data races at root
- **Performance**: Zero-cost abstractions

## 2. Core Concepts - Ownership System

> **One-line Definition**  
> **"Every value has exactly one owner"** - Rust's golden rule

### Three Rules of Ownership

1. Each value has an owner variable
2. Only one owner can exist at a time
3. When owner goes out of scope, value is dropped

```
fn main() {
    // s1 is owner of String
    let s1 = String::from("hello");

    // Ownership moves to s2
    let s2 = s1;

    // println!("{}", s1); // Error! s1 no longer valid
    println!("{}", s2); // OK: "hello"
}
```

### Borrowing - Using Without Ownership

```
fn main() {
    let s = String::from("hello");

    // Borrow using &
    let len = calculate_length(&s);

    println!("Length of '{}' is {}", s, len); // s still usable!
}

fn calculate_length(s: &String) -> usize {
    s.len() // Use value without ownership
}
```

### ② Implementation - Simple Todo App

```
// main.rs
use std::io;

#[derive(Debug)]
struct Todo {
    id: u32,
    task: String,
    completed: bool,
}

impl Todo {
    // Create new Todo
    fn new(id: u32, task: String) -> Self {
        Todo {
            id,
            task,
            completed: false,
        }
    }

    // Mark complete
    fn complete(&mut self) {
        self.completed = true;
    }
}

fn main() {
    let mut todos: Vec<Todo> = Vec::new();
    let mut id_counter = 1;

    loop {
        println!("\n=== Todo App ===");
        println!("1. Add todo");
        println!("2. View list");
        println!("3. Mark complete");
        println!("4. Exit");

        let mut choice = String::new();
        io::stdin().read_line(&mut choice).expect("Input failed");

        match choice.trim() {
            "1" => {
                println!("Enter task:");
                let mut task = String::new();
                io::stdin().read_line(&mut task).expect("Input failed");

                todos.push(Todo::new(id_counter, task.trim().to_string()));
                id_counter += 1;
                println!("✅ Added!");
            }
            "2" => {
                println!("\n📋 Todo List:");
                for todo in &todos {
                    let status = if todo.completed { "✓" } else { "○" };
                    println!("{} [{}] {}", status, todo.id, todo.task);
                }
            }
            "3" => {
                println!("Item number to complete:");
                let mut id_str = String::new();
                io::stdin().read_line(&mut id_str).expect("Input failed");

                if let Ok(id) = id_str.trim().parse::<u32>() {
                    if let Some(todo) = todos.iter_mut().find(|t| t.id == id) {
                        todo.complete();
                        println!("✅ Completed!");
                    }
                }
            }
            "4" => {
                println!("👋 Goodbye!");
                break;
            }
            _ => println!("❌ Invalid choice"),
        }
    }
}
```

## 4. Best Practices & Tips

| Pattern | Advantage | Caution |
| --- | --- | --- |
| **Use Result<T, E>** | Explicit error handling | Avoid unwrap() overuse |
| **Leverage Iterators** | Functional programming style | Balance readability vs performance |
| **Implement Traits** | Polymorphism & code reuse | Avoid over-abstraction |
| **Explicit Lifetimes** | Compile-time safety | Increased complexity |

### 💡 Practical Tips

```
// ❌ Bad example
let data = get_data().unwrap(); // Panic risk!

// ✅ Good example
let data = match get_data() {
    Ok(d) => d,
    Err(e) => {
        eprintln!("Error occurred: {}", e);
        return;
    }
};

// ✅ Better example (? operator)
let data = get_data()?;
```
