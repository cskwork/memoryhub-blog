> Make sure to handle several essential configuration items before starting your project!

![](/images/4-%EC%84%A4%EC%A0%95-%EC%9A%94%EA%B5%AC%EC%82%AC%ED%95%AD/chris-ried-512801-unsplash.jpg)

**Essential Requirements**

- Right-click project - build path configuration register latest JAVA SE .X
- Register Tomcat WAS (Web Application Server) and integrate with project. Check module name
- Download Maven and register necessary LIBs in pom.xml
- Configure encoding method to UTF-8 in web.xml or server.xml
- Set entire project encoding method to UTF-8
- Verify that applicaiton-servlet path homeController and view prefix, suffix are correctly configured in viewResolver
- Confirm localhost:xxxx domain server is set to your configuration

**Additional Requirements**

- Register auxiliary tools like js, css, JSTL, EL in JSPF and configure path connections in pages using them
- Register appropriate dependency when using json, xml
- Do the same when using AOP, jackson (multipartFile), Logging
- Create and pre-configure interface tools like AbstractDAO, CommandMap, Interceptor, ArgumentResolver, Validator, Authenticator classes
