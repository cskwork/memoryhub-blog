Hello. You can attach AI to DBeaver to perform **natural language to SQL generation, query explanation/refactoring** and more. You can connect various models including OpenAI, Azure OpenAI, Google Gemini, GitHub Copilot, and Ollama (local LLM).

![](/images/771-DBeaver에서도-AI-Chat-가능합니다-다만-에디션-보안-설정이-핵심/img.png)

---

## **📋 What Can You Do? (Quick Feature Map)**

- **Natural Language → SQL**: Convert sentences like "recent orders only last 7 days" to SQL
- **Query Explanation/Refactoring**: Break down and improve long SQL step by step
- **AI Chat Window**: Conversational interface for queries, preview, and confirmation before execution (Query preview/confirmation added from 25.2)
- **Local/On-Premises OK**: **Ollama** connection available, custom OpenAI Base URL supported from 25.2 → Advantageous for in-house gateways/proxies

---

## **🔧 Edition Differences (Important)**

Edition | AI Smart Completion (Natural Language→SQL popup) | AI Chat (Conversational Window) | Sample Data Send Option

|  |  |  |  |
| --- | --- | --- | --- |
| **Community** | **Supported** (run via toolbar icon) | Not supported | Not supported |
| **Lite / Enterprise / Ultimate / Team** | Supported | **Supported** | **Supported** |

- **Community** focuses on "AI Smart Completion", while **pro editions** (Lite/Enterprise/Ultimate/Team) unlock **AI Chat** and sample data send features.
- From 2025.07 onward, **Community installations come with AI integration bundled**, but depending on environment, **AI extension installation** may be needed (based on release notes).

## **⚙️ Setup in 3 Steps (Quickest Path)**

1. **Menu**: Window → Preferences → General → AI → Check **Enable AI integration**
2. **Choose Provider**: Select from OpenAI / Azure OpenAI / Gemini / Copilot / Ollama. Providers other than OpenAI and Copilot are currently available only in paid editions.
3. **Enter Key**: Save your service key (API token) → Call with **@ai** or **AI icon** in SQL editor
4. (If pro: open the chat window with the **AI Chat** icon in the toolbar)

---

## **🔐 Security & Privacy Checklist (Practical Setup)**

DBeaver can send **metadata (table/column names, data types, foreign keys, etc.)** to AI for better accuracy, and pro editions can also transmit **some sample data rows**. Each item has an **ON/OFF toggle** so you can minimize it.

- **AI Settings Location**: Preferences → General → AI
  - *Send database structure / column data types / object descriptions / foreign keys* etc. - **individual transmission control**
  - *Sample data* and **row count** are **only available in pro editions** → **OFF recommended** by default
- **Narrow Scope**: Limiting the **schema/table range** that AI references reduces unnecessary metadata transmission and token consumption.
- **Prevent Dangerous Queries**: **Confirmation popup for destructive queries generated by AI** (dangerous query confirmation) has been added (per version release notes).
- **Complete Disable**: If needed, you can turn off AI integration entirely. Preferences → General → AI → Disable
- **Policy Notice**: Some paid plans may **restrict third-party app usage**, so check the terms.

## **❓ Troubleshooting/Prevention Tips**

- **AI not visible in Community**: Check AI extension/integration status (extension installation may be **required depending on version**).
- **Feel like too much metadata is being sent**: Narrow the **Scope** and adjust transmission items (especially Object descriptions/Types) and **turn off sample data**. Related issues have been reported.
- **In-house/On-Premises models**: Connect local models via **Ollama** or set internal proxy in **Custom Base URL**.

---

## **📝 Quick Reference Guide (One Page)**

**Recommended Basic Settings**

1. Provider: Choose model matching company policy (prefer **Ollama/in-house gateway** if possible)
2. Transmission Items: **Minimal structure + Sample Data OFF**
3. Scope: **Specify only working schema/tables**
4. Before Execution: **Turn on AI query confirmation popup** (released feature)

**Tips by Use Case**

- Learning/Beginner: Start with **Smart Completion** for simple queries
- Team/Production: **Pro edition + Chat** for standardized prompts/refactoring templates

- **Smart Completion (Community)**: Left **AI icon** in SQL Editor → Translate
- **Completely Turn Off AI**: Preferences → General → AI → Disable
