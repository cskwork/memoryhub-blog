- Learned about the pricing policies needed for AWS S3 and EC2 usage. Basically, there's no cost when moving or storing files internally, but pricing is highly segmented for computing resource usage, storage usage, load balancing usage, and more. You can check this through the cost explorer.

- Server management is more efficient and clear when using Docker containers. I reviewed Coolify, an open-source platform for Next.js deployment and integration, and decided to use it since it's popular and used in real-world cases. Vercel has low initial costs but expenses grow exponentially as the scale increases. You can also check the processes and capacity that Docker uses. Containers use capacity in ~10MB units, but images typically take up more space.

- Each instance has SSH-key integration, and you need to set the private key required for connections (using tools like PuTTY, Terminus, MobaXterm) based on that key.

- Google created NotebookLM, which seems like a RAG tool for non-developers. For developers, AnythingLLM is more useful because you can choose the desired LLM and control it the way you want.
