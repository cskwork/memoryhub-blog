## Operations

### Relational Algebra

**Relation**:

**Algebra**: (a field of mathematics that studies general properties of mathematical structures) a set of operators

**General Set Operators**

| Operator | Description |
| --- | --- |
| Union (UNION, ∪) | A binary operation that combines two relations to create a single new relation. |
| Intersection (INTERSECT, ∩) | A binary operation that selects duplicate content from two relations to create a new relation. |
| Difference (DIFFERENCE, -) | A binary operation that removes overlapping content from one relation when comparing with another relation to create a new relation. |
| Cartesian Product (CARTESIAN PRODUCT, ×) | A binary operation that creates all possible combinations of tuples from two relations. Result relation degree = R's degree + S's degree. Result relation cardinality = R's cardinality × S's cardinality. |

**Pure Set Operators**

| Operator | Description |
| --- | --- |
| Selection (SELECT, σ) | A unary operation that separates records matching a condition from a relation. It takes a horizontal subset from a single relation. |
| Projection (PROJECT, π) | A unary operation that selects and separates attributes to be referenced from a relation. It takes a vertical subset from a single relation. Duplicate tuples in the result are removed. |
| Join (JOIN, ⨝) | An operation that creates a new relation by combining tuples or attributes matching a condition from two or more relations. |

### Relational Calculus

**Calculus**: (based on the concepts of differential and integral calculus, it studies properties of function continuity) expressions represented in relational algebra are expressed in relational calculus.

| Category | Component | Symbol | Description |
| --- | --- | --- | --- |
| Operator | OR Operation | ∨ | Connects atomic formulas with an "or" relationship |
| | AND Operation | ∧ | Connects atomic formulas with an "and" relationship |
| | NOT Operation | ¬ | Negation of an atomic formula |
| Quantifier | Universal Quantifier | ∀ | For all possible tuples "For All" # Reversed form of 'A' in All ★ |
| | Existential Quantifier | ∃ | There exists at least one tuple "There Exists" # Reversed form of 'E' in Exists ★ |
