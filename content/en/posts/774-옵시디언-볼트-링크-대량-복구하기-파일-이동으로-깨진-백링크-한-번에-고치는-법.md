## 🔴 Problem Situation

When using Obsidian, you often move files around as you organize folder structures. Especially when doing major reorganization because your initial folder structure isn't satisfactory.

I recently reorganized my learning materials with the following changes:

- **Before**: `Resources/학습자료/중요자료/`
- **After**: `30_Resources/14_Learning/중요자료/`

The problem was that while I moved the files, **over 175 backlinks were completely broken!** 😱

## 📊 Broken Link Pattern Analysis

The broken links fell into two types:

### 1. Regular Backlinks

```
[[Resources/학습자료/중요자료/네트워크/스위치]]
```

### 2. Image Embeds

```
![[Resources/학습자료/중요자료/attachments/이미지.png]]
```

There were too many to fix manually one by one, so I needed a more efficient approach.

## ⚙️ Solution Process

### Step 1: Problem Analysis

First, I confirmed which files were affected.

```
# Find files with broken links
find . -name "*.md" -type f -exec grep -l "Resources/학습자료" {} \;
```

### Step 2: Create Backup (Important!)

Always create a backup before making bulk changes.

```
# Commit current state with Git or copy entire folder
cp -r "vault-folder" "vault-folder_backup"
```

### Step 3: Bulk Link Fix

Here's the **key command**. This single line solved most of the problem:

```
# Command explanation included
# `find . -name "*.md" -type f`: Find all markdown files in current folder
# Modify file contents directly with sed -i command
# Using `|` as separator: Many `/` characters in paths, so use `|` as separator
find . -name "*.md" -type f -exec sed -i '' 's|Resources/학습자료/|30_Resources/14_Learning/|g' {} \;
```

### Step 4: Resolve Relative Path Issues

I found some files with relative path references:

```
![[../attachments/이미지.png]]
```

For these cases, I changed them individually to absolute paths:

```
![[30_Resources/14_Learning/중요자료/attachments/이미지.png]]
```

## ✅ Verification Results

### Verify Modification Completion

```
# Check if old pattern still exists
find . -name "*.md" -exec grep -l "Resources/학습자료" {} \;

# Verify new pattern was properly changed
find . -name "*.md" -exec grep -c "30_Resources/14_Learning" {} \; | awk '{s+=$1} END {print "Modified links: " s}'
```

### 🔍 Useful Verification Commands

```
# Search for specific pattern
grep -r "search-pattern" .

# Count links
find . -name "*.md" -exec grep -c "\[\[.*\]\]" {} \; | awk '{s+=$1} END {print s}'

# Find empty links
find . -name "*.md" -exec grep -l "\[\[\]\]" {} \;
```

## 🎯 Conclusion

To properly leverage Obsidian's powerful backlink system, it's important to know these bulk modification techniques. Especially as your vault grows, manual work becomes practically impossible.

**⚡ Pro Tip**: Before making major folder structure changes, always manage versions with Git or create a backup of your entire vault. Safety is the top priority!
