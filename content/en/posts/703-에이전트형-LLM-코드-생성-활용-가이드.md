## 📌 Overview

Agentic LLMs are next-generation development tools where AI proactively writes, modifies, and tests code. Beyond simple autocompletion, tools like GitHub Copilot and ChatGPT understand entire codebases and complete tasks.

## 🎯 Core Usage Strategy

### ✅ Strengths

• **Automation of Repetitive Tasks**: Unit tests, boilerplate code

• **Debugging Support**: Correcting syntax errors, debugging assistance

• **Documentation**: Code explanation, comment addition

### ⚠️ Precautions

• **"Trust but Verify"** - AI code always requires review

• **Security/Optimization Weaknesses**: Outdated libraries, inefficient implementations possible

• **Missing Exception Handling**: Manual verification of edge cases essential

## 🏆 Language-Specific Best Practices

### **Java**

```
// Use clear naming and JavaDoc

 * @return Session token
```

**Key Points:**

• Follow CamelCase naming

• Use JavaDoc to clarify intent

• Use TODO comments to guide AI

## 💡 Effective Prompt Writing

### 1️⃣ **Step-by-Step Approach**

```
❌ "Write the entire program for me"
✅ "Step 1: Input validation" → "Step 2: Core logic" → "Step 3: Output processing"
```

### 2️⃣ **Specific Requirements**

```
❌ "Write fast code"
✅ "Work with O(N) time complexity, output 'Invalid input' on error"
```

### 3️⃣ **Provide Examples**

```
// Input: 'abc123' → true
// Input: '@@' → false
// Write regex matching the above pattern
```

## 🔧 Practical Usage Examples

### **Request Code Explanation**

```
"Explain what this recursive function does in plain English"
→ AI breaks down complex code clearly
```

### **Debug Errors**

```
Error: KeyError: 'user_id'
"Tell me the cause and solution for this KeyError"
→ Shows missing key handling method
```

### **Generate Tests**

```
"Write pytest test code for the above functions"
→ Automatically generates normal and error cases
```

## 🎓 Core Principles to Remember

1. **Clear Intent Communication** - Treat AI like a fellow developer
2. **Gradual Improvement** - Don't expect perfect code first time
3. **Always Verify** - AI code can contain bugs too
4. **Continuous Learning** - Monitor new AI capabilities

### 📚 Terminology

- **Agentic Code Generation**: AI agent-based approach where code is generated by understanding user intentions and goals, making decisions autonomously.
- **AI Pair Programming**: Method where developers collaborate with AI on code writing and review.
- **Copilot**: GitHub's AI code generation tool.
- **Prompt**: Input sentence instructing AI to perform desired tasks.
- **Agentic LLM**: AI coding assistant that plans and executes tasks autonomously
- **Boilerplate**: Repetitive, standard code patterns • **Prompt**: Input sentence instructing AI to perform tasks
