> An essential feature once the basic bulletin board is complete - user registration!

![](/images/9-회원가입/micah-williams-436268-unsplash.jpg)

**Required Requirements**

- Registration, login, logout, member list, member details, member info modification, withdrawal - total 7 pages needed (or some can be omitted with AJAX processing)
- Java classes - Controller, ServiceImpl, Service (Interface), DAO, abstractDAO (completed set of methods implementing map basic functions), CommandMap/TO (bean value storage)
- XML file **sql.xml (queryId) - CRUD registration
- Required queries - CRUD // insert, select, update, update


**Additional Requirements**

- Handle sessions with LoginInterceptor, AdminInterceptor and verify login session when navigating pages to controller
- Use AJAX to prevent duplicate member registration during signup
- Implement password/ID recovery functionality
- Maintain login session - save in cookie functionality
- Password encryption when storing in DB - use BCrypt class, etc.


**Code Analysis**

**Login Functionality**
> Summary: When processing login, need VO/map to verify login information and HttpSession to store login information in session.
