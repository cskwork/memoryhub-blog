*Hello! Have you experienced inconvenience because the Hancom input method was automatically installed along with Hancom Office? Today, let's learn how to remove the Hancom input method from Windows.*

## Background

Hancom Office is a widely used document program in Korea, but when installed, the 'Hancom Input Method' is automatically installed as well. As a result, two input methods coexist on the system: Microsoft Input Method and Hancom Input Method. This situation sometimes causes inconvenience for users.

Reasons for removing the Hancom input method:

1. **Input Method Differences**: Can confuse users accustomed to Microsoft input method
2. **Auto-conversion Issues**: Potential errors in Korean/English auto-conversion
3. **Consonant-Vowel Separation**: Korean input sometimes separates consonants and vowels like 'ㄱㅏㄴㅏㄷㅏ'

## Core Principle

The process of removing the Hancom input method from Windows can be divided into two main steps:

1. Remove Hancom input method in Windows settings
2. Change input method settings in Hancom Office

Below is a diagram of this process:

```
[Start] → [Settings] → [Time and Language] → [Language & region] → [Korean] → [Language options] 
        → [Hancom input method] → [Remove] → [Done!]
```

## Removing Hancom Input Method from Windows Settings

1. **Open Settings Window**

   - Click the Start button on the taskbar and select 'Settings', or
   - Use the Windows key + I shortcut to open the Settings window.
2. **Navigate to Language Settings**

   - In the Settings window, click 'Time and Language'.
   - Select 'Language & region' from the left menu.
3. **Open Korean Options**

   - In the Language section, click the 'More (⋯)' button on the right of the 'Korean' item.
   - Select 'Language options' from the dropdown menu.
4. **Remove Hancom Input Method**

   - Find 'Hancom input method' in the Keyboard section.
   - Click the 'More (⋯)' button on the right of 'Hancom input method' and select 'Remove'.
   - After restart, only Microsoft input method will remain.

## Changing Input Method Settings in Hancom Office

Hancom Office has independent input method settings, so even if you remove the Hancom input method from Windows settings, it may still be used within Hancom Office. Here's how to change it:

1. **Run Hancom Office Hangul**

   - Run the Hancom Office Hangul program.
2. **Open Input Method Environment Settings**

   - Navigate to the 'Tools' tab at the top menu.
   - Click 'Keyboard' and select 'Change Keyboard (K)', or
   - Use the shortcut key Alt + F2.
3. **Change to Windows Input Method**

   - When the 'Input Method Settings' window opens, click the 'Current Keyboard (C):' dropdown menu.
   - Select 'Windows Input Method'.
   - Click 'Apply (A)' and 'OK' buttons to save the settings.

## Precautions and Tips

Warning: **Pay careful attention to these points!**

1. When removing the input method, be careful not to accidentally remove the wrong one.

   - Check which input method you primarily use before removing.
   - Generally, it's best to keep only the Microsoft input method.
2. If the consonant/vowel separation persists:

   - Try changing 'Previous version of Microsoft IME' to 'On' in Microsoft IME input method settings.

Tip **Golden Tip**

- Click the input method icon on the taskbar to check which input method is currently active.
- If you want to reinstall the Hancom input method, you can add it from 'Add keyboard' in Language settings.
- Depending on the situation, Windows restart may be required, so save important work before proceeding.

## Closing Remarks

So far, we've learned how to remove the Hancom input method from Windows. While it may seem complicated at first, you'll find it's not difficult if you follow the steps. I hope this article helps you create a better computer experience!
