> Documentation work before project launch!!

**Essential Requirements**

1. Item Selection (Precisely understand and analyze client/customer/buyer requirements) / Identify needs
2. Use Case Diagram (Analyze user action scenarios)
3. Action Mapping (URI -> Service)
4. Table Design - Logical and physical design (Draw relationships and set Primary, Foreign Keys; identify necessary data categories for project execution)
5. Scheduling, task allocation
6. Documentation integration, organization (Convert to PowerPoint materials)

**Additional Requirements**

  When designing tables, it's convenient to generate numbers in advance with IDX seq and implement paging logic.
