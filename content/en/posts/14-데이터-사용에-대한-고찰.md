> When analyzing any feature or code (exploration, analysis requirements), key criteria to use as benchmarks

**Essential Requirements**

- Data container + container mapping
- Data location <URI>
- How to retrieve/send data <GET/POST>
- Data type <JSON, XML, HTML, VARCHAR, NUMBER, DATE, FORM, BUTTON, POJO>
- Data content/role
- Data size
- Data parameters <container type + contents>
- Data return value <O/VOID>
- Data CRUD operations
- Data configuration <required libs/classes, modules>

**Additional Requirements**

- Data events <SYNC, ASYNC: time-based>
- Data change type
- Data iteration <index>
- Data sorting <tempUse>
- Data filtering
- Data exception handling
- Data logging
- Data grouping number/container
- Data creation, modification, deletion
- Data history
- Data user
- Data encoding
