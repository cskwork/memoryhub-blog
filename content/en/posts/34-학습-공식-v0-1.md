Deep Learning Steps

1 Get Problem

2 Search, collect and analyze solved examples related to the problem

3 Apply and test it out

4 Check Answer

CLASSIC LEARNING = INPUT DATA + RULES -> OUTPUT DATA

DEEP LEARNING - INPUT DATA + EXAMPLES -> FIGURE OUT THE RULES

T Learning - Broad yet specialized in a few.

Hash-Tag Extraction - Keywords vital to understanding.

Make (Process-based) Manual

If stuck trace the caller of the referenced object and clearly understand it.

Always optimize understanding and definition to get just the essence.
