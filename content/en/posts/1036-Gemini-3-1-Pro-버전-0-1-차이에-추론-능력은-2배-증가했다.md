A "0.1" difference in AI model names usually means a minor update.

You typically expect bug fixes and slight performance improvements.

But Google's Gemini 3.1 Pro, released on February 19, 2026, completely overturned that assumption.

Its performance more than doubled compared to its predecessor on the abstract logic reasoning benchmark (ARC-AGI-2), and it became the most powerful AI model in existence according to Artificial Analysis evaluations.

**What hides behind the humble number "0.1" is essentially a generational leap in reasoning capability.**

**One-liner summary:** In short, Gemini 3.1 Pro is Google's current strongest AI model, more than doubling the reasoning performance of its predecessor Gemini 3 Pro while maintaining the same price.

---

## Background

In November 2025, Google launched Gemini 3 Pro and briefly held the "world's strongest AI model" title. But AI competition is unforgiving. Within mere weeks, OpenAI and Anthropic released new models and took the crown. Google needed a quick counterattack, and the result is Gemini 3.1 Pro.

> Gemini 3.1 Pro is the next-generation model of the Gemini 3 series, with substantially enhanced core reasoning capabilities.
> It is Google's current most advanced AI model.

This model draws attention for a simple reason: **"At the same price, it's become much smarter."**

It maintained the existing API pricing structure of Gemini 3 Pro while dramatically improving reasoning quality.

From a developer's perspective, it's like getting a performance upgrade without changing a single line of code.

Interestingly, Google has shifted its version naming strategy. In the previous generation, it did mid-cycle updates from 2.0 to 2.5, using "0.5" increments.

Using "0.1" units for the first time suggests Google has switched to faster iteration cycles.

## Core: What Improved and How Much

The most dramatic change in Gemini 3.1 Pro appears in reasoning benchmarks. It's not just "improved"—the numbers have entered a completely different orbit.

### Benchmark Scorecard

| Benchmark | Measurement Area | Gemini 3 Pro | Gemini 3.1 Pro | Change |
| --- | --- | --- | --- | --- |
| ARC-AGI-2 | Abstract Logic Reasoning | 31.1% | 77.1% | +148% |
| GPQA Diamond | Scientific Knowledge | 91.9% | 94.3% | +2.4%p |
| SWE-Bench Verified | Practical Coding | - | 80.6% | - |
| LiveCodeBench Pro | Coding Elo | - | 2887 | - |
| MMMLU | Multimodal Understanding | - | 92.6% | - |

The ARC-AGI-2 benchmark might be unfamiliar. It measures whether a model can solve **completely new logical patterns it has never seen before**. Because it evaluates true "thinking" ability rather than mere memorization or pattern matching, it's a metric particularly noted by AI researchers.

A useful analogy: if traditional benchmarks measure "how well you solve math problem sets," ARC-AGI-2 measures "can you figure out the rules and solve a puzzle of a completely new type you've never encountered?" A more-than-doubling performance here isn't just incremental improvement—it means the model's way of thinking itself has fundamentally changed.

### Comparison with Competing Models

Based on ARC-AGI-2, current major competing models' performance is as follows:

| Model | ARC-AGI-2 Score |
| --- | --- |
| **Gemini 3.1 Pro** | **77.1%** |
| Anthropic Claude Opus 4.6 | 68.8% |
| OpenAI GPT-5.2 | 52.9% |
| Gemini 3 Pro (previous) | 31.1% |

By these numbers, Gemini 3.1 Pro has reclaimed first place in reasoning capability.

However, benchmark scores don't always match real-world user experience. Particularly, scores announced by companies themselves may have different evaluation conditions, so independent third-party verification is important. The fact that independent evaluation agencies like Artificial Analysis also rate 3.1 Pro as the highest-performing model strengthens credibility.

## What Can It Actually Do: Changed Use Cases

Benchmark numbers are abstract. Google's concrete examples show how this performance improvement creates real differences in actual tasks.

**Automated Data Visualization Construction**: 3.1 Pro can fetch data directly from public APIs and construct dashboards.

In a case demonstrated by Google, the model independently connected NASA's public telemetry data to create a dashboard that visualizes the International Space Station (ISS) orbit in real-time.

**Code-based Animation Generation**: Generates animation SVGs that can be directly inserted into websites from just a text prompt.

This means non-designers can create interactive visual elements with just text descriptions.

**Visual Explanation of Complex Topics**: Ability to convert abstract concepts into simulations or interactive tools for explanation has been strengthened.

Google describes this as "intelligence applied"—intelligence translating beyond chat into actual functional results.

The key point is that 3.1 Pro is not simply "a chatbot that answers better" but is evolving into **"an agent that independently connects tools and creates results."**

## Access Methods and Pricing

### Who Can Use It and Where

3.1 Pro is currently available in Preview status through the following channels:

- **General Users**: Gemini app (higher usage limits for Google AI Pro/Ultra subscribers), NotebookLM (Pro/Ultra subscribers only)
- **Developers**: Gemini API (AI Studio), Gemini CLI, Google Antigravity (agent development platform), Android Studio
- **Enterprises**: Vertex AI, Gemini Enterprise

Preview status means it's in a phase of additional validation for safety and performance. GA (general availability) is scheduled soon, and Google stated that additional improvements will be made especially in the agent workflow area.

### API Pricing

| Item | Price |

## Gemini 3 Series Overall Structure

To properly understand Gemini 3.1 Pro, you need to know the structure of the entire Gemini 3 series.

| Model | Positioning | Suitable Use |
| --- | --- | --- |
| Gemini 3 Flash | Speed/cost-optimized baseline | Daily conversation, summarization, bulk processing |
| Gemini 3 Pro | High-performance reasoning | Complex analysis, coding, agents |
| **Gemini 3.1 Pro** | **3 Pro reasoning-enhanced version** | **High-difficulty reasoning, science/research** |
| Gemini 3 Deep Think | Ultra-high-difficulty thinking mode | Mathematics, scientific challenges, research (Ultra exclusive) |

All three models share the same 1M token context window, but the **depth of processing** that context differs.

Flash processes quickly, Pro analyzes deeply, Deep Think reasons precisely with time.
