Imagine using IntelliJ with keyboard shortcuts as naturally as using a car remote. Using only the mouse to operate IntelliJ is like manually unlocking a car door with a key. But using shortcuts is as efficient as controlling everything with a remote! 🚀

- Shortcuts make development work magically fast
- Your hands never leave the keyboard, so your workflow isn't interrupted
- Complex tasks can be handled with just a few key presses

## Why is it needed?

IntelliJ shortcuts solve these problems:

1. **Time Saving**: Reduces time spent navigating menus with the mouse
2. **Maintain Workflow**: Use needed features without interrupting coding focus
3. **Reduce Repetitive Tasks**: Perform frequently used functions faster
4. **Reduce Physical Fatigue**: Minimize wrist strain by reducing mouse use

## Basic Principles

Let's understand the core principles of IntelliJ shortcuts:

### Categorical Organization

IntelliJ shortcuts are broadly divided into five categories based on purpose:

1. Navigation shortcuts
2. Editing shortcuts
3. Refactoring shortcuts
4. Search shortcuts
5. Run/Debug shortcuts

### Shortcut Combination Patterns

Most shortcuts follow this pattern:

```
Ctrl/⌘ + [Function Key]  # Basic function
Ctrl/⌘ + Shift + [Function Key]  # Extended function
Alt/⌥ + [Function Key]  # Alternative function
```

## Practical Examples

Let's explore the 20 most frequently used IntelliJ shortcuts by category.

### 1. Navigation Shortcuts 🧭

#### Search Everywhere (Double Shift / Double Shift)

The ultimate shortcut for finding everything. Searches for classes, files, symbols, actions, and everything else.

```
// To find the User class, press double Shift and type 'User'
// Can search only classes with "c:" prefix, only files with "f:" prefix
```

#### Go to Class (Ctrl+N / ⌘O)

Quickly find any class in the project.

```
// To jump to UserService class, press Ctrl+N and type 'UserService'
// Supports CamelCase matching - just type 'US' to find UserService
```

#### Go to File (Ctrl+Shift+N / ⌘⇧O)

Open files by filename regardless of location.

```
// To go to application.properties, press Ctrl+Shift+N and type 'app'
// Wildcards and directory structure also available (*/test/*.java)
```

#### Recent Files (Ctrl+E / ⌘E)

Opens a popup showing a list of recently opened files.

```
// To return to a file you just viewed, press Ctrl+E and select the file
// Press twice to show only recently edited files
```

#### Go to Declaration (Ctrl+B or Ctrl+Click / ⌘B or ⌘Click)

Jump directly to the declaration of variables, methods, or classes.

```
// Position cursor on method call and press Ctrl+B to jump to method definition
// Use Ctrl+Alt+B (⌘⌥B) to jump to the implementation
```

### 2. Editing Shortcuts ✏️

#### Smart Code Completion (Ctrl+Shift+Space / ⌃⇧Space)

Context-aware code completion that filters methods and variable lists based on expected type.

```
// After typing String s = obj., press Ctrl+Shift+Space to show only String-returning methods
```

#### Complete Statement (Ctrl+Shift+Enter / ⌘⇧↩︎)

Adds necessary syntax elements (semicolons, braces, etc.) to complete the current statement.

```
// After typing if (condition, press Ctrl+Shift+Enter to complete as if (condition) { }
```

#### Duplicate Line (Ctrl+D / ⌘D)

Duplicates the current line or selected block.

```
// Position on String name = "John"; line and press Ctrl+D to duplicate below
```

#### Comment Line (Ctrl+/ / ⌘/)

Toggles comment on the current line.

```
// Position on System.out.println("Debug"); and press Ctrl+/ to comment/uncomment
```

#### Reformat Code (Ctrl+Alt+L / ⌘⌥L)

Organizes code formatting according to code style settings.

```
// Select code block with messy indentation and press Ctrl+Alt+L to clean up
```

### 3. Refactoring Shortcuts 🔧

#### Rename (Shift+F6 / ⇧F6)

Safely rename elements with automatic updates of all references.

```
// Position cursor on UserService class name and press Shift+F6 to rename to 'CustomerService'
// All references are automatically updated
```

#### Extract Variable (Ctrl+Alt+V / ⌘⌥V)

Extract an expression into a variable.

```
// Select calculateTotal(price, tax) expression and press Ctrl+Alt+V
// Converts to: double total = calculateTotal(price, tax);
```

#### Extract Method (Ctrl+Alt+M / ⌘⌥M)

Extract code snippet into a method.

```
// Select multiple lines of code and press Ctrl+Alt+M to extract into separate method
```

#### Show Intention Actions (Alt+Enter / ⌥↩)

Displays context-aware actions and quick fixes.

```
// Position cursor on unresolved variable and press Alt+Enter to see import suggestions and variable creation options
```

#### Refactor This (Ctrl+Alt+Shift+T / ⌃T)

Displays all available refactoring options.

```
// Position cursor on method and press Ctrl+Alt+Shift+T to show all refactoring options for this context
```

### 4. Search Shortcuts 🔍

#### Find (Ctrl+F / ⌘F)

Find text in the current file.

```
// Press Ctrl+F and type "Exception" to highlight all occurrences in current file
```

#### Find in Path (Ctrl+Shift+F / ⌘⇧F)

Search across the entire project or specific directory.

```
// Use Ctrl+Shift+F to search "deprecated" across entire project
```

#### Replace (Ctrl+R / ⌘R)

Replace text in the current file.

```
// Press Ctrl+R to replace "oldMethod" with "newMethod"
```

#### Find Action (Ctrl+Shift+A / ⌘⇧A)

Find actions or options by name without navigating through menus.

```
// Press Ctrl+Shift+A and type "Maven" to show all Maven-related actions
```

### 5. Run and Debug Shortcuts 🚀

#### Run (Shift+F10 / ⌃R)

Execute the current configuration.

```
// Press Shift+F10 in file with main() method to run application
```

#### Debug (Shift+F9 / ⌃D)

Debug the current configuration.

```
// Press Shift+F9 to start application in debug mode
// Use with breakpoints for efficient debugging
```

## Cautions and Tips 💡

⚠️ **Important to remember!**

1. Shortcut Conflicts
   - Shortcuts may conflict with other programs or OS
   - Can be customized in Settings > Keymap
2. MacBook Issues
   - Some shortcuts may conflict with system shortcuts on macOS
   - Disable or change conflicting shortcuts in system settings
3. Over-reliance
   - Don't try to memorize all shortcuts at once
   - Start with 5-10 frequently used ones and gradually increase

💡 **Pro Tips**

- Print a keymap reference card and stick it next to your monitor
- Download PDF version from Help > Keymap Reference
- For the first 2 weeks, intentionally reduce mouse use and practice shortcuts
- Learning just 2-3 shortcuts per category significantly improves productivity
- Use the Key Promoter X plugin to see shortcuts for actions you perform with the mouse
