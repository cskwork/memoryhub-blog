With web-based Claude Code, you can start coding sessions without opening a terminal. Simply connect your GitHub repository and describe the task you need done—Claude handles the implementation.

Each session runs in an isolated environment with real-time progress tracking, and you can adjust Claude's direction anytime during the work.

Because Claude Code runs in the cloud, you can now execute tasks across multiple repositories in parallel from a single interface, and deploy faster with automatic PR generation and clear change summaries.

### Flexible for Every Workflow

The web interface complements your existing Claude Code workflow. Running tasks in the cloud is particularly effective for:

- Answering questions about how projects work and repository structure
- Bug fixes and everyday, clearly defined tasks
- Backend changes—Claude Code can validate changes using test-driven development

You can also use Claude Code on mobile. As part of this research preview, we're providing Claude Code in the iOS app so developers can experience coding with Claude while on the go. This is still an early preview stage, and we plan to improve the mobile experience quickly based on your feedback.

### Security-First Cloud Execution

All Claude Code tasks run in isolated sandbox environments with network and filesystem restrictions. Git interactions are handled through a security proxy service that ensures Claude only accesses authorized repositories, protecting your code and credentials throughout the entire workflow.

You can also add custom network configuration to control which domains Claude Code can connect to from the sandbox. For example, you can allow Claude to download npm packages over the internet to run tests and validate changes.
