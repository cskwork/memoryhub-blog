> By performing AND operations on IP address 192.169.35.10 and subnet mask 255.255.252.0 in binary, you get the network address 192.169.32.0. Setting all host bits to 1 gives the broadcast address 192.169.35.255. The actual usable IP range is 192.169.32.1 through 192.169.35.254.

## Background

### Why Subnet Calculation is Necessary

To manage networks efficiently, you must divide IP address space appropriately. Splitting a single large network into multiple smaller networks (subnets) offers advantages in security, performance, and management.

| Term | Definition | Role |
| --- | --- | --- |
| IP Address | Unique identifier for a device on the network | Format like 192.169.35.10 |
| Subnet Mask | Distinguishes network portion from host portion | Represented as 255.255.252.0 |
| Network Address | Starting address of the subnet | Cannot be assigned to devices, used for identification |
| Broadcast Address | Ending address of the subnet | Sends simultaneously to all devices |
| Host Range | IPs actually available for device assignment | Network+1 through broadcast-1 |

### Problem Situation

Existing problems include scenarios where "not understanding subnets led to putting all PCs in the same range, causing broadcast storms" or "incorrect IP range settings caused communication failures."

## Core Concept

> The subnet mask is a filter that distinguishes IP addresses into network and host portions. AND operations yield the network address, and filling host bits with 1 produces the broadcast address.

### Calculation Principles

**Binary Structure of Subnet Mask**

- 255 = 11111111 (network bits, fixed)
- 252 = 11111100 (partially network, partially host)
- 0 = 00000000 (host bits, variable)

**AND Operation Rules**

- 1 AND 1 = 1
- 1 AND 0 = 0
- 0 AND 0 = 0

Applying these rules to IP and subnet mask calculations yields the network address.

## Practice

### Step 1: Understand the Problem

Organize the given information:

- PC IP Address: 192.169.35.10
- Subnet Mask: 255.255.252.0
- Goal: Find the broadcast-capable IP range

### Step 2: Calculate Network Address

The key is calculating the 3rd octet (35 AND 252):

**Binary Conversion**

```
IP Address 35:      0010 0011
Subnet Mask 252:    1111 1100
```

**Perform AND Operation**

```
  0010 0011  (35)
& 1111 1100  (252)
-----------
  0010 0000  (32)
```

**Interpret Results**

- 3rd Octet: 32
- Network Address: **192.169.32.0**

This is the starting point of the subnet this PC belongs to.

### Step 3: Calculate Broadcast Address

Fill all host bits with 1:

**Host Bits in Subnet Mask 252**

```
1111 1100
     ^^-- These 2 bits are the host area
```

**Change Host Bits to 1 from Network Address**

```
0010 0000 (32, network address)
0010 0011 (35, set host bits to 11)
```

**Calculate 4th Octet**

```
0000 0000 (0, network address)
1111 1111 (255, set all bits to 1)
```

**Result**

- Broadcast Address: **192.169.35.255**

### Step 4: Derive Usable IP Range

Network and broadcast addresses cannot be assigned to devices, so exclude them:

- Start: 192.169.32.0 (network address, not usable)
- First Host: **192.169.32.1**
- Last Host: **192.169.35.254**
- End: 192.169.35.255 (broadcast address, not usable)

**Total Usable IP Count**

- Formula: 2^(host bits) - 2
- Host Bits: 2 bits (3rd octet) + 8 bits (4th octet) = 10 bits
- Count: 2^10 - 2 = 1024 - 2 = **1022 IPs**

### Step 5: Verify

Confirm the PC's IP address 192.169.35.10 falls within the calculated range:

- 192.169.32.1 ≤ **192.169.35.10** ≤ 192.169.35.254 ✓

The PC is within range, so it can communicate with all devices in the same subnet via broadcast.

## Best Practices/Pattern Comparison

| Subnet Mask | Host Bits | Usable IP Count | Note |
| --- | --- | --- | --- |
| 255.255.255.0 (/24) | 8 bits | 254 | Small network, simple calculation, most common |
| 255.255.252.0 (/22) | 10 bits | 1022 | Medium network, 3rd octet calculation required |
| 255.255.248.0 (/21) | 11 bits | 2046 | Large network, management complexity increases |
| 255.255.255.128 (/25) | 7 bits | 126 | Fine-grained division, useful for VLAN design |

## Conclusion

Subnet calculation operates on the simple principles of binary AND operations and host bit manipulation. The 192.169.35.10/22 network accommodates 1022 devices from 192.169.32.1 to 192.169.35.254, with broadcast address 192.169.35.255 enabling full network communication. Mastering this calculation lets you propose IP allocation plans on the spot in network design meetings and prevent communication errors during equipment configuration.

**Practical Application Tips**: Verify with online subnet calculators, but understanding the principles allows you to troubleshoot abnormal situations. Especially when configuring firewall rules, knowing precise network ranges allows you to apply security policies correctly.
