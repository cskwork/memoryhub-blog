- Aider provides templates, but you need to manually adjust and create detailed prompts to meet your requirements. For longer contexts, it's more effective and cost-efficient to transfer the issue to ChatGPT to resolve it. Generally, using it for a day costs around $2.

- To manage security rigorously, you can parse accounts with IAM and manually apply permissions to specific areas, for example, a single S3 bucket or item.

- Use Cost Explorer to manage detailed costs and set up alerts for excessive expenses.

- Cursor IDE is also useful as an AI copilot like Aider, but since the usage period is short and the paid version costs $20, it's quite expensive.

- Dockerfile alone sometimes doesn't work well for reading Prisma config and running migrations in a Linux environment. Docker-compose works normally and is more useful. When you run `docker-compose up`, you can also check logs through VSCode IDE. Store configuration files in `.env` and read from there.

- There is a way to build Docker containers on Windows and upload them, but it takes a very long time, and you need to pay attention to hardware compatibility (AMD, ARM, etc.) depending on the Linux architecture. It's better to upload the code to the server, run `docker build`, and then deploy.
