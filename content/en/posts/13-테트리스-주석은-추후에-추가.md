> Tetris game built using basic JavaScript

**Tetris.html**

A complete implementation of the Tetris game in HTML5 Canvas with JavaScript, featuring:

- Game board with 10x20 blocks
- Tetris piece rotations and movements
- Row clearing mechanics
- Score tracking
- Next piece preview
- Responsive design with media queries

[Full Tetris implementation with HTML5 Canvas and JavaScript - see the original source for complete code]

**Key Features:**

- Arrow keys for movement (LEFT, RIGHT) and rotation (UP)
- DOWN arrow to speed up piece drop
- SPACE key to start/play
- ESC to quit/lose
- Real-time score and row count display
- Upcoming piece preview canvas
- Responsive responsive layout that scales with screen size

**Game Mechanics:**

- Pieces spawn at the top and fall down
- Rows are cleared when completely filled
- Score increases by 10 for each piece dropped
- Score increases exponentially for multiple rows cleared (100, 200, 400, 800)
- Game speed increases as more rows are completed
- Game ends when pieces reach the top
