Key Differences Between Java 8 and Java 18

1. Lambda Expressions (Java 8)

   Lambda expressions introduced in Java 8 enable functional programming.

   ```
   // Before Java 8
   Runnable runnable = new Runnable() {
       @Override
       public void run() {
           System.out.println("Hello, World!");
       }
   };

   // After Java 8
   Runnable runnable = () -> System.out.println("Hello, World!");
   ```
2. Stream API (Java 8)

   Makes it possible to process collections more efficiently.

   ```
   List<String> names = Arrays.asList("John", "Jane", "Adam", "Eve");

   // Before Java 8
   List<String> filteredNames = new ArrayList<>();
   for (String name : names) {
       if (name.startsWith("J")) {
           filteredNames.add(name.toUpperCase());
       }
   }

   // After Java 8
   List<String> filteredNames = names.stream()
       .filter(name -> name.startsWith("J"))
       .map(String::toUpperCase)
       .collect(Collectors.toList());
   ```
3. Default Methods (Java 8)

   Interfaces can now include implementations.

   ```
   interface Vehicle {
       default void start() {
           System.out.println("Vehicle starting...");
       }
   }

   class Car implements Vehicle {
       // No need to override the start() method
   }
   ```
4. New Date/Time API (Java 8)

   A new API was introduced to address problems with the existing Date and Calendar.

   ```
   // Before Java 8
   Date date = new Date();
   Calendar calendar = Calendar.getInstance();
   calendar.add(Calendar.DAY_OF_MONTH, 1);

   // After Java 8
   LocalDate today = LocalDate.now();
   LocalDate tomorrow = today.plusDays(1);
   ```
5. var Keyword (Java 10)

   Supports local variable type inference.

   ```
   // Before Java 10
   String message = "Hello, World!";

   // After Java 10
   var message = "Hello, World!";
   ```
6. Improved Switch Expressions (Java 12, 13, 14)

   Switch statements can be written more concisely.

   ```
   // Before Java 12
   String result;
   switch (day) {
       case MONDAY:
       case FRIDAY:
       case SUNDAY:
           result = 6;
           break;
       case TUESDAY:
           result = 7;
           break;
       case THURSDAY:
       case SATURDAY:
           result = 8;
           break;
       case WEDNESDAY:
           result = 9;
           break;
       default:
           throw new IllegalStateException("Invalid day: " + day);
   }

   // After Java 12
   String result = switch (day) {
       case MONDAY, FRIDAY, SUNDAY -> "6";
       case TUESDAY                -> "7";
       case THURSDAY, SATURDAY     -> "8";
       case WEDNESDAY              -> "9";
       default -> throw new IllegalStateException("Invalid day: " + day);
   };
   ```
7. Text Blocks (Java 13, 14, 15)

   Multi-line strings can be written more easily.

   ```
   // Before Java 13
   String json = "{\n" +
                 "  \"name\": \"John Doe\",\n" +
                 "  \"age\": 30\n" +
                 "}";

   // After Java 13
   String json = """
                 {
                   "name": "John Doe",
                   "age": 30
                 }
                 """;
   ```
8. Records (Java 14, 15, 16)

   Immutable data objects can be created simply.

   ```
   // Before Java 14
   public class Person {
       private final String name;
       private final int age;

       public Person(String name, int age) {
           this.name = name;
           this.age = age;
       }

       // getters, equals, hashCode, toString
   }

   // After Java 14
   public record Person(String name, int age) {}
   ```
9. Pattern Matching for instanceof (Java 14, 15, 16)

   Type checking and casting can be done in one step.

   ```
   // Before Java 14
   if (obj instanceof String) {
       String s = (String) obj;
       // use s
   }

   // After Java 14
   if (obj instanceof String s) {
       // s is immediately available
   }
   ```
10. Sealed Classes (Java 15, 16, 17)

    Class inheritance can be restricted.

    ```
    public sealed class Shape
        permits Circle, Rectangle, Square {
        // ...
    }

    public final class Circle extends Shape {
        // ...
    }

    public final class Rectangle extends Shape {
        // ...
    }

    public final class Square extends Shape {
        // ...
    }
    ```

These new features make code more concise, easier to read, and improve developer productivity. Additionally, versions after Java 8 have continued to evolve in various aspects including performance improvements, security enhancements, and API improvements.
