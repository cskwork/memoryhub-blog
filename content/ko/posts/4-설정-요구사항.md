> 프로젝트를 시작하기 전에 꼭 설정을 해야 하는 몇 가지 필수 사항들을 먼저 정리~~!

![](/images/4-설정-요구사항/chris-ried-512801-unsplash.jpg)

**필수 요구사항**

- 프로젝트 우클릭 - build path configuration JAVA SE .X 최신 버전 등록하기
- 톰켓 WAS(Web Application Sever) 등록하고 프로젝트와 연동. 모듈 이름 확인
- 메이븐 가져와서 필요한 LIB를 pom.xml에 등록
- web.xml 또는 sever.xml에 encoding 방식 UTF-8로 설정
- 전체 프로젝트 엔코딩 방식 UTF-8로 설정
- applicaiton-servlet 경로 homeController와 뷰. prefix, suffix로 viewResolver에서 구현하는 경로가 맞게 설정되었는지 확인
- localhost:xxxx domain sever가 본인이 설정한 걸로 돼있는지 확인


**추가 요구사항**

- 사용하는 부가적인 도구 js, css, JSTL, EL등을 JSPF로 등록해서 사용하는 페이지에 경로 연동/설정
- json, xml 사용시 그에 해당하는 dependency 등록하기
- AOP, jackson (multipartFile), Loggging 사용시도 마찬가지
- AbstractDAO, CommandMap, Interceptor, ArgumentResolver, Validator, Authenticator 등 인터페이스 도구로 사용할 클래스 미리 만들어서 설정해두기
