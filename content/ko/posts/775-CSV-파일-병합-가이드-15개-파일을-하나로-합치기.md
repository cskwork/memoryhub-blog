## 개요

15개의 CSV 파일을 하나의 파일로 병합하는 방법을 소개합니다. 이 가이드는 macOS/Linux 환경에서 터미널을 사용하는 방법을 설명합니다.

## 상황

- **대상 파일들**: `_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111`로 시작하는 15개 CSV 파일
- **파일 구성**: 기본 파일 1개 + 번호가 붙은 파일 14개 (\_2.csv ~ \_15.csv)
- **총 용량**: 약 140MB
- **총 데이터**: 160만 행 이상

## 단계별 실행 방법

### 1단계: 파일 확인

```
# CSV 파일 목록 확인
ls -la *연구용*111*.csv

# 파일 개수 확인
ls -1 *연구용*111*.csv | wc -l
```

### 2단계: 파일 순서 확인

```
# 올바른 순서로 파일명 생성
printf '%s\n' _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111.csv _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_{2..15}.csv
```

### 3단계: 기본 파일 복사

```
# 첫 번째 파일을 병합 결과 파일로 복사 (헤더 포함)
cp "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111.csv" "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv"
```

### 4단계: 나머지 파일들 순차 병합

```
# 파일 2번부터 15번까지 헤더 제외하고 데이터만 추가
for i in {2..15}; do 
    echo "Adding file _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_${i}.csv"
    tail -n +2 "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_${i}.csv" >> "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv"
done
```

### 5단계: 결과 검증

```
# 개별 파일들의 행 수 확인
echo "개별 파일들의 행 수:"
for file in _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111.csv _연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_{2..15}.csv; do 
    echo "$file: $(wc -l < "$file")"
done

# 병합된 파일의 행 수 확인
echo "병합된 파일의 행 수:"
wc -l "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv"

# 최종 파일 정보
ls -lh "*merged.csv"
head -2 "_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv"
```

## 실행 결과

- **병합 완료 파일**: `_연구용_학습_활동_메모_북마크_펜도구_플래그_추출_기간_2025_03_04_00_00__2025091014181111_merged.csv`
- **파일 크기**: 138MB
- **총 행 수**: 1,605,541행 (헤더 1행 + 데이터 1,605,540행)
- **검증**: ✅ 개별 파일 총합에서 중복 헤더 14개 제거한 수와 일치

## 핵심 포인트

1. **순서가 중요**: 파일명의 숫자 순서대로 병합
2. **헤더 처리**: 첫 번째 파일만 헤더 포함, 나머지는 `tail -n +2`로 헤더 제외
3. **검증 필수**: 행 수 계산으로 데이터 누락 없음 확인
4. **효율성**: `for` 루프와 `tail` 명령으로 자동화

## 다른 상황에 응용하기

파일명이 다른 경우, 다음 부분만 수정하면 됩니다:

- 기본 파일명 패턴
- 파일 번호 범위 `{2..15}` → `{2..N}`
- 출력 파일명

이 방법을 사용하면 대용량 CSV 파일들도 메모리 효율적으로 병합할 수 있습니다.
