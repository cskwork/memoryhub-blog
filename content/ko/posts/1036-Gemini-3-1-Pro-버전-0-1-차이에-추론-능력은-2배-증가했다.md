AI 모델 이름에서 "0.1" 차이는 보통 사소한 업데이트를 의미합니다.

버그 수정, 약간의 성능 개선 정도를 기대하는 게 일반적이죠.

그런데 Google이 2026년 2월 19일 공개한 Gemini 3.1 Pro는 그 상식을 완전히 뒤집었습니다.

추상적 논리 추론 벤치마크(ARC-AGI-2)에서 전작 대비 성능이 2배 이상 뛰었고,

Artificial Analysis 평가에서는 현존 가장 강력한 AI 모델로 등극했습니다.

**"0.1"이라는 겸손한 숫자 뒤에 숨어 있는 것은, 사실상 세대급 추론 능력의 도약입니다.**

**한줄요약:** 결론부터 말하면, Gemini 3.1 Pro는 전작 3 Pro 대비 추론 성능을 2배 이상 끌어올리면서도 가격은 동일하게 유지한,

Google의 현시점 최강 AI 모델입니다.

---

## 배경

2025년 11월, Google은 Gemini 3 Pro를 출시하며 잠시 "세계 최강 AI 모델" 타이틀을 거머쥐었습니다. 하지만 AI 경쟁은 냉정합니다. 불과 몇 주 만에 OpenAI와 Anthropic이 새 모델을 내놓으며 왕좌를 빼앗겼습니다. Google 입장에서는 빠른 반격이 필요했고,

그 결과물이 바로 Gemini 3.1 Pro입니다.

> Gemini 3.1 Pro는 Gemini 3 시리즈의 차세대 모델로, 핵심 추론 능력(core reasoning)을 대폭 강화한   
> Google의 현재 가장 진보된 AI 모델입니다.

이 모델이 주목받는 이유는 단순합니다. **"똑같은 가격에, 훨씬 더 똑똑해졌다"**는 것입니다.

기존 Gemini 3 Pro의 API 가격 구조를 그대로 유지하면서, 추론 품질만 대폭 끌어올렸습니다.

개발자 입장에서는 코드 한 줄 바꾸지 않고 성능 업그레이드를 받는 셈입니다.

흥미로운 점은 Google의 버전 명명 전략 변화입니다. 이전 세대에서는 2.0에서 2.5로, 즉 "0.5" 단위로 중간 업데이트를 했습니다.

이번에 "0.1" 단위를 처음 사용한 것은 Google이 더 빠른 반복 주기(iteration cycle)로 전환했음을 시사합니다.

---

## 핵심: 무엇이 얼마나 좋아졌나

Gemini 3.1 Pro의 가장 극적인 변화는 추론 벤치마크에서 드러납니다. 단순히 "좋아졌다"가 아니라,

수치가 완전히 다른 궤도에 진입했습니다.

### 벤치마크 성적표

| 벤치마크 | 측정 영역 | Gemini 3 Pro | Gemini 3.1 Pro | 변화 |
| --- | --- | --- | --- | --- |
| ARC-AGI-2 | 추상 논리 추론 | 31.1% | 77.1% | +148% |
| GPQA Diamond | 과학 지식 | 91.9% | 94.3% | +2.4%p |
| SWE-Bench Verified | 코딩 실무 | - | 80.6% | - |
| LiveCodeBench Pro | 코딩 Elo | - | 2887 | - |
| MMMLU | 멀티모달 이해 | - | 92.6% | - |

ARC-AGI-2라는 벤치마크가 낯설 수 있습니다. 이건 모델이 **이전에 본 적 없는 완전히 새로운 논리 패턴**을 풀 수 있는지 측정하는

시험입니다. 단순 암기나 패턴 매칭이 아니라, 진짜 "사고"에 가까운 능력을 평가한다는 점에서 AI 연구자들이 특히 주목하는 지표입니다.

쉽게 비유하면, 기존 벤치마크가 "수학 문제집을 얼마나 잘 푸는가"라면 ARC-AGI-2는 "처음 보는 유형의 퍼즐을 스스로 규칙을 파악해서 풀 수 있는가"에 해당합니다. 여기서 2배 이상 뛴 것은 단순한 성능 향상이 아니라,

모델의 사고 방식 자체가 질적으로 달라졌음을 의미합니다.

### 경쟁 모델과의 비교

ARC-AGI-2 기준으로 현재 주요 경쟁 모델들의 성적은 다음과 같습니다.

| 모델 | ARC-AGI-2 점수 |
| --- | --- |
| **Gemini 3.1 Pro** | **77.1%** |
| Anthropic Claude Opus 4.6 | 68.8% |
| OpenAI GPT-5.2 | 52.9% |
| Gemini 3 Pro (전작) | 31.1% |

이 수치대로라면 Gemini 3.1 Pro가 현시점에서 추론 능력 1위를 탈환한 셈입니다.

다만, 벤치마크 점수가 실제 사용 경험과 항상 일치하지는 않는다는 점은 감안해야 합니다. 특히 각 회사가 자체적으로

발표하는 점수는 평가 조건이 다를 수 있어,

독립적인 제3자 검증이 중요합니다. Artificial Analysis 같은 독립 평가 기관에서도 3.1 Pro를 현존 최고 성능 모델로 평가한 점은

신뢰도를 높여줍니다.

## 실제로 뭘 할 수 있나: 달라진 활용 사례

벤치마크 숫자는 추상적입니다. Google이 구체적으로 보여준 사례들은 이 성능 향상이 실제 작업에서

어떤 차이를 만드는지 잘 보여줍니다.

**데이터 시각화 자동 구성**: 3.1 Pro는 공개 API에서 데이터를 직접 가져와 대시보드를 구성할 수 있습니다.

Google이 시연한 사례에서는 NASA의 공개 원격 측정 데이터를 모델이 스스로 연결해

국제우주정거장(ISS)의 궤도를 실시간으로 시각화하는 대시보드를 만들었습니다.

**코드 기반 애니메이션 생성**: 텍스트 프롬프트만으로 웹사이트에 바로 삽입 가능한 애니메이션 SVG를 생성합니다.

디자이너가 아니더라도 텍스트 설명만으로 인터랙티브한 시각 요소를 만들 수 있다는 의미입니다.

**복잡한 주제의 시각적 설명**: 추상적인 개념을 시뮬레이션이나 인터랙티브 도구로 변환해 설명하는 능력이 강화되었습니다.

Google은 이를 "intelligence applied", 즉 지능이 채팅을 넘어 실제 기능적 결과물로 이어지는 방향이라고 설명합니다.

핵심은, 3.1 Pro가 단순히 "더 잘 대답하는 챗봇"이 아니라

**"도구를 스스로 연결하고, 결과물을 직접 만들어내는 에이전트"**로 진화하고 있다는 것입니다.

## 접근 방법과 가격

### 누가, 어디서 쓸 수 있나

3.1 Pro는 현재 Preview(미리보기) 상태로 다음 채널에서 제공됩니다.

- **일반 사용자**: Gemini 앱 (Google AI Pro/Ultra 구독자에게 높은 사용 한도 제공), NotebookLM (Pro/Ultra 구독자 전용)
- **개발자**: Gemini API (AI Studio), Gemini CLI, Google Antigravity(에이전트 개발 플랫폼), Android Studio
- **기업**: Vertex AI, Gemini Enterprise

Preview 상태라는 것은 안전성과 성능을 추가 검증하는 단계라는 뜻입니다. 조만간 GA(정식 출시)가 예정되어 있으며,

특히 에이전트 워크플로우 영역에서 추가 개선이 이루어질 것이라고 Google은 밝혔습니다.

### API 가격

| 항목 | 가격 |
| --- | --- |
| 입력 (200K 토큰 이하) | $2.00 / 1M 토큰 |
| 입력 (200K 토큰 초과) | $4.00 / 1M 토큰 |
| 출력 (200K 토큰 이하) | $12.00 / 1M 토큰 |
| 출력 (200K 토큰 초과) | $18.00 / 1M 토큰 |
| Context Caching | $0.20~$0.40 / 1M 토큰 + 저장 $4.50/시간 |
| Search Grounding | 월 5,000 프롬프트 무료, 이후 $14 / 1,000 쿼리 |

가격은 Gemini 3 Pro와 동일합니다. 성능은 2배, 가격은 그대로. 개발자 입장에서 이것만으로도 업그레이드 이유가 충분합니다.

## Gemini 3 시리즈 전체 구도 정리

Gemini 3.1 Pro를 제대로 이해하려면, 전체 Gemini 3 시리즈의 구조를 알아야 합니다.

| 모델 | 포지셔닝 | 적합한 용도 |
| --- | --- | --- |
| Gemini 3 Flash | 속도/비용 최적화 기본 모델 | 일상 대화, 요약, 대량 처리 |
| Gemini 3 Pro | 고성능 추론 모델 | 복잡한 분석, 코딩, 에이전트 |
| **Gemini 3.1 Pro** | **3 Pro의 추론 강화 버전** | **고난도 추론, 과학/연구** |
| Gemini 3 Deep Think | 초고난도 사고 모드 | 수학, 과학 난제, 연구 (Ultra 전용) |

세 모델 모두 동일한 1M 토큰 컨텍스트 윈도우를 공유하지만, 그 컨텍스트를 **처리하는 깊이**가 다릅니다.

Flash는 빠르게 훑고, Pro는 깊이 분석하고, Deep Think는 시간을 들여 정밀하게 추론합니다.

## 마치며

- Gemini 3.1 Pro는 "0.1" 업데이트라는 이름과 달리, ARC-AGI-2 기준 추론 성능을 31.1%에서 77.1%로 2배 이상 끌어올린 실질적인 세대급 업그레이드입니다.
- API 가격은 전작과 동일하게 유지되어, 개발자는 추가 비용 없이 성능 향상을 누릴 수 있습니다. 현재 Preview 상태이며, 정식 출시가 곧 예정되어 있습니다.
- 실전 팁: Google AI Studio(ai.google.dev)에서 지금 바로 Gemini 3.1 Pro Preview를 테스트해보고, 기존 Gemini 3 Pro 기반 워크플로우와 결과 품질을 비교해보세요.
