*안녕하세요! 한컴 오피스를 설치했더니 자동으로 한컴 입력기도 함께 설치되어 불편함을 겪고 계신가요? 오늘은 윈도우에서 한컴 입력기를 제거하는 방법을 알아보겠습니다.*

## 등장 배경

한컴 오피스는 우리나라에서 많이 사용하는 문서 프로그램이지만, 설치할 때 자동으로 '한컴 입력기'도 함께 설치됩니다. 그 결과 시스템에는 Microsoft 입력기와 한컴 입력기 두 가지가 공존하게 되죠. 이런 상황이 가끔 사용자에게 불편함을 가져오곤 합니다.

한컴 입력기 제거가 필요한 이유:

1. **입력 방식 차이**: Microsoft 입력기에 익숙한 사용자들에게 혼란을 줄 수 있음
2. **자동 변환 문제**: 한글/영어 자동 변환 오류 발생 가능
3. **자음 모음 분리 현상**: 한글 입력 시 'ㄱㅏㄴㅏㄷㅏ'처럼 자음과 모음이 분리되는 현상 발생

## 핵심 원리

윈도우에서 한컴 입력기를 제거하는 과정은 크게 두 단계로 나눌 수 있습니다.

1. 윈도우 설정에서 한컴 입력기 제거
2. 한컴 오피스 내 입력기 설정 변경

아래는 이 과정을 그림으로 표현한 것입니다:

```
[시작] → [설정] → [시간 및 언어] → [언어 및 지역] → [한국어] → [언어 옵션] 
        → [한컴 입력기] → [제거] → [완료!]
```

## 윈도우 설정에서 한컴 입력기 제거하기 ?

1. **설정 창 열기**

   - 작업 표시줄에서 시작 버튼을 클릭하고 '설정'을 선택하거나
   - Windows 키 + I 단축키를 사용하여 설정 창을 엽니다.
2. **언어 설정으로 이동**

   - 설정 창에서 '시간 및 언어'를 클릭합니다.
   - 왼쪽 메뉴에서 '언어 및 지역'을 선택합니다.
3. **한국어 옵션 열기**

   - 언어 섹션에서 '한국어' 항목 오른쪽의 '더 보기(⋯)' 버튼을 클릭합니다.
   - 드롭다운 메뉴에서 '언어 옵션'을 선택합니다.
4. **한컴 입력기 제거**

   - 키보드 섹션에서 '한컴 입력기'를 찾습니다.
   - '한컴 입력기' 오른쪽의 '더 보기(⋯)' 버튼을 클릭하고 '제거'를 선택합니다.
   - 재시작 후 Microsoft 입력기만 남게 됩니다.

## 한컴 오피스 내 입력기 설정 변경하기 ?️

한컴 오피스에는 독립적인 입력기 설정이 있으므로, 윈도우 설정에서 한컴 입력기를 제거해도 한컴 오피스 내에서는 계속 사용될 수 있습니다. 이를 변경하는 방법은 다음과 같습니다:

1. **한컴 오피스 한글 실행**

   - 한컴 오피스 한글 프로그램을 실행합니다.
2. **입력기 환경 설정 열기**

   - 상단 메뉴에서 '도구' 탭으로 이동합니다.
   - '글자판'을 클릭하고 '글자판 바꾸기(K)'를 선택하거나
   - 바로가기 키 Alt + F2를 사용합니다.
3. **윈도우 입력기로 변경**

   - '입력기 환경 설정' 창이 열리면, '현재 글자판(C):' 드롭다운 메뉴를 클릭합니다.
   - '윈도우 입력기'를 선택합니다.
   - '적용(A)'과 '확인' 버튼을 클릭하여 설정을 저장합니다.

## 주의사항 및 팁 ?

⚠️ **이것만은 주의하세요!**

1. 입력기 제거 시 실수로 잘못된 입력기를 제거하지 않도록 주의하세요.

   - 제거 전 어떤 입력기를 주로 사용하는지 확인하세요.
   - 일반적으로 Microsoft 입력기만 남기는 것이 좋습니다.
2. 자음/모음 분리 현상이 계속된다면:

   - Microsoft IME 입력기 설정에서 '이전 버전의 Microsoft IME'를 '켬'으로 변경해보세요.

? **꿀팁**

- 작업 표시줄에서 입력기 아이콘을 클릭하면 현재 활성화된 입력기를 확인할 수 있어요.
- 한컴 입력기를 다시 설치하고 싶다면, 언어 설정의 '키보드 추가'에서 추가할 수 있습니다.
- 상황에 따라 윈도우 재시작이 필요할 수 있으니 중요한 작업은 저장 후 진행하세요.
