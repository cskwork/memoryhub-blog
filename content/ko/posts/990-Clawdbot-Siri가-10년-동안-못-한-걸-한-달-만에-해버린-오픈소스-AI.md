"이메일 정리해줘"라고 말하면 진짜로 이메일을 정리하는 AI가 있다면 어떨까요. 캘린더를 확인하고, 파일을 만들고, 심지어 필요한 기능이 없으면 스스로 코드를 짜서 추가하는 AI 말입니다.

ChatGPT나 Claude에게 "이메일 보내줘"라고 하면 "이렇게 보내면 됩니다"라는 설명만 돌아오는 것과는 차원이 다른 이야기입니다.

**Clawdbot은 "대화하는 AI"가 아니라 "실제로 일하는 AI"입니다.** 그것도 오픈소스로, 당신의 컴퓨터에서 24시간 돌아가면서요.

**한줄요약:** Clawdbot은 내 컴퓨터에 상주하며 WhatsApp/Telegram으로 지시를 받아 이메일, 캘린더, 파일 관리를 실제로 수행하는 오픈소스 AI 에이전트다.

## 배경

AI 어시스턴트 시장은 역설적인 상황에 놓여 있습니다. GPT-4, Claude Opus 같은 최신 모델들은 인간 수준의 추론 능력을 갖췄지만, 정작 우리 일상에서 "실제로 뭔가를 해주는" 수준에는 미치지 못합니다. Siri는 2011년에 출시됐고, 빅스비는 2017년부터 있었지만,

2026년인 지금도 "오늘 회의 자료 정리해서 팀에 공유해줘"라는 요청은 처리하지 못합니다.

> Clawdbot은 LLM이 실제로 컴퓨터를 조작할 수 있게 해주는 오픈소스 개인 AI 에이전트다.

이 간극을 메운 것이 한 개인 개발자의 오픈소스 프로젝트입니다. Peter Steinberger(iOS 개발 커뮤니티에서 PSPDFKit으로 유명한 인물)가 만든 Clawdbot은 2025년 말 출시 이후 한 달도 안 되어 GitHub 스타 8,000개를 돌파하며 개발자 커뮤니티를 뒤흔들었습니다. MacStories의 Federico Viticci는 이 프로젝트를 두고 "개인 AI 어시스턴트의 미래를 보여줬다"고 평가했습니다.

왜 대기업들이 수년간 못 한 일을 개인 프로젝트가 해냈을까요. 답은 단순합니다.

접근 방식이 완전히 달랐기 때문입니다.

## Clawdbot이 다른 AI 어시스턴트와 근본적으로 다른 점

### 1. 로컬 실행: 당신의 컴퓨터에 "상주"한다

ChatGPT나 Claude는 클라우드에서 실행됩니다. 당신이 질문을 보내면 서버에서 답변을 생성해 돌려보내는 방식입니다.

반면 Clawdbot은 **당신의 Mac, Windows, Linux 컴퓨터에서 직접 실행**됩니다.

이게 왜 중요한가요. 로컬에서 실행된다는 건 당신의 파일 시스템, 터미널, 브라우저에 직접 접근할 수 있다는 뜻입니다.

"바탕화면에 있는 보고서.docx 파일 열어서 요약해줘"라고 하면 진짜로 파일을 열어서 읽습니다.

"구글 캘린더에서 이번 주 일정 확인해줘"라고 하면 브라우저를 제어해서 실제로 확인합니다.

### 2. 메시징 앱 통합: 이미 쓰는 앱에서 대화한다

Clawdbot의 또 다른 핵심은 **게이트웨이** 시스템입니다. 별도의 앱을 설치할 필요 없이,

이미 사용 중인 WhatsApp, Telegram, Discord, Slack, Signal, iMessage에서 Clawdbot과 대화할 수 있습니다.

출퇴근길에 카카오톡 하듯 텔레그램으로 "오늘 받은 이메일 중 중요한 거 정리해줘"라고 보내면, 집에 있는 Mac mini에서 돌아가는 Clawdbot이 Gmail에 접속해 이메일을 분류하고 요약본을 텔레그램으로 보내줍니다.

마치 원격으로 일하는 비서에게 메시지를 보내는 것과 같습니다.

### 3. 자기 개선: 필요한 기능을 스스로 만든다

가장 충격적인 부분입니다. Clawdbot은 자신에게 없는 기능이 필요하면 **직접 코드를 작성해서 추가**합니다.

MacStories의 Viticci는 "Clawdbot에게 구글 Nano Banana 이미지 생성 기능을 추가해달라고 했더니, API 문서를 찾아보고, 자격 증명을 macOS 키체인에 안전하게 저장하는 방법까지 알려주면서 스스로 기능을 구현했다"고 전했습니다.

Clawdbot의 모든 설정과 기능은 **로컬 폴더의 마크다운 파일**로 저장됩니다.

Obsidian처럼 모든 게 텍스트 파일이라 투명하게 확인하고 수정할 수 있습니다. AI가 뭘 하는지 블랙박스가 아닙니다.

## 실제 활용 사례

### 사례 1: 자동 모닝 브리핑

MacStories 에디터는 매일 아침 Clawdbot이 자동으로 보내주는 브리핑을 받습니다. 구글 캘린더의 오늘 일정, Notion의 할 일 목록, Todoist의 우선순위 작업을 종합해 텔레그램 메시지로 전송합니다. 텍스트 버전과 함께 ElevenLabs TTS로 생성한 **음성 버전**까지 함께요. 이 모든 게 cron job 하나로 돌아갑니다.

### 사례 2: Zapier 자동화 대체

기존에 Zapier로 월 구독료를 내며 운영하던 자동화를 Clawdbot으로 대체한 사례도 있습니다. "매주 금요일 뉴스레터 발송 후 RSS 피드를 확인해서 Todoist에 다음 호 프로젝트 생성"이라는 작업을 Clawdbot에게 설명했더니,

5분 만에 cron job과 스크립트를 직접 작성해 설정했습니다. 클라우드 의존성 없이, 구독료 없이,

내 컴퓨터에서 돌아가는 자동화가 완성됐습니다.

### 사례 3: 음성 명령과 음성 응답

텔레그램으로 음성 메시지를 보내면 Whisper 모델로 텍스트 변환하고, 작업을 처리한 뒤, ElevenLabs로 음성 응답을 생성해 돌려보냅니다. 한국어와 영어가 섞인 음성도 문제없이 처리합니다. Siri가 아직도 다국어 혼용을 제대로 못 하는 것과 대조적입니다.

## Clawdbot의 핵심 구성 요소

| 구성 요소 | 역할 | 특징 |
| --- | --- | --- |
| **Gateway** | 메시징 앱과 연결되는 제어 허브 | launchd/systemd 데몬으로 24시간 실행 |
| **Agent** | 실제 작업을 수행하는 LLM 에이전트 | Claude, GPT, Gemini 등 모델 선택 가능 |
| **Skills** | 기능 확장 모듈 | 커뮤니티 제공 또는 직접 생성 가능 |
| **Memory** | 대화 기록과 사용자 선호도 저장 | 마크다운 파일로 로컬 저장 |
| **Channels** | 지원 메시징 플랫폼 | WhatsApp, Telegram, Discord, Slack, Signal, iMessage 등 |

## 설치 방법

Clawdbot은 macOS, Windows(WSL2 권장), Linux에서 실행됩니다. Node.js 22 이상이 필요합니다.

**1단계: 설치**

```
# 원라인 설치 (권장)
curl -fsSL https://clawd.bot/install.sh | bash

# 또는 npm으로 설치
npm install -g clawdbot
```

**2단계: 온보딩**

```
clawdbot onboard --install-daemon
```

온보딩 위자드가 실행되면서 LLM 제공자 선택(Anthropic, OpenAI, Google 등), 메시징 채널 연결, 기본 스킬 설정을 안내합니다.

**3단계: 메시징 앱 연결**

텔레그램 연결을 예로 들면, BotFather에서 봇 토큰을 받아 Clawdbot 설정에 입력하면 됩니다. 이후 텔레그램에서 봇에게 메시지를 보내면 내 컴퓨터의 Clawdbot이 응답합니다.

## 주의사항과 한계

Clawdbot은 강력하지만, 아직 "얼리어답터용" 프로젝트입니다. 몇 가지 알아둘 점이 있습니다.

첫째, **API 비용**입니다. Clawdbot은 선택한 LLM 제공자의 API를 사용합니다. MacStories 에디터는 일주일 사용에 1억 8천만 토큰을 소모했다고 밝혔습니다. Claude Opus 기준으로 상당한 비용이 발생할 수 있습니다. 비용을 줄이려면 GPT-4o-mini나 Claude Haiku 같은 경량 모델을 사용하거나, 로컬 모델(MiniMax, Ollama)을 활용하는 방법이 있습니다.

둘째, **보안 고려**입니다. Clawdbot은 컴퓨터에 대한 광범위한 접근 권한을 가집니다. 이메일, 파일, 터미널 명령 실행이 가능하다는 건 편리함과 동시에 위험성을 의미합니다. 신뢰할 수 있는 네트워크에서만 사용하고,

DM 정책을 "pairing" 모드로 설정해 허가된 사용자만 접근하도록 하는 것이 권장됩니다.

셋째, **기술적 진입장벽**입니다. 설치 과정이 npm, CLI에 익숙한 사람에게는 간단하지만, 비개발자에게는 여전히 어려울 수 있습니다.

다만 macOS용 메뉴바 앱이 베타로 제공되고 있어, 점차 접근성이 개선되고 있습니다.

## 마치며

- Clawdbot은 대화만 하는 AI가 아니라 내 컴퓨터에서 실제로 작업을 수행하는 24시간 상주 에이전트입니다.
- 오픈소스이며, 모든 설정과 메모리가 로컬 마크다운 파일로 저장되어 완전한 투명성과 커스터마이징이 가능합니다.
- WhatsApp, Telegram 등 기존 메시징 앱에서 명령을 내리고 결과를 받아볼 수 있어, 별도의 앱 없이 어디서든 AI 비서를 활용할 수 있습니다.

실전 팁: Mac mini나 여분의 노트북이 있다면 Clawdbot 전용 서버로 세팅해보세요.

메인 작업 컴퓨터와 분리해두면 안전하게 실험할 수 있습니다.
