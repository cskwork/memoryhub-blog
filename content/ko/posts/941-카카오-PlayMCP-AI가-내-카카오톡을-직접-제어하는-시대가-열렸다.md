"AI한테 오늘 일정 알려달라고 했더니 캘린더 앱을 직접 열어보라고 한다." 이런 경험, 누구나 한 번쯤 있을 것이다. AI가 아무리 똑똑해도 내 캘린더, 내 메시지, 내 음악 앱에 접근할 수 없다면 진정한 '비서'가 될 수 없다. **카카오의 PlayMCP는 바로 이 벽을 허무는 국내 최초의 시도다.**

**결론부터 말하면, PlayMCP는 AI가 카카오톡, 멜론, 캘린더 등 카카오 서비스를 직접 제어할 수 있게 만드는 개방형 플랫폼이며, 카카오 계정만 있으면 누구나 사용하거나 개발에 참여할 수 있다.**

---

## 배경

AI 비서의 한계는 분명했다. ChatGPT든 Claude든, 아무리 대화를 잘해도 "내 카카오톡에 메모 남겨줘"라는 요청은 처리할 수 없었다. AI 모델과 외부 서비스가 서로 '다른 언어'를 쓰고 있었기 때문이다.

2024년 11월, Anthropic이 이 문제를 해결하기 위해 MCP(Model Context Protocol)를 발표했다. 그리고 2025년 7월, 카카오가 국내 최초로 MCP 기반 개방형 플랫폼 PlayMCP를 베타 오픈했다.

> **MCP(Model Context Protocol)란?** AI 모델이 외부 데이터나 도구와 소통하는 방식을 표준화한 통신 규약이다. USB-C 포트 하나로 다양한 기기를 연결하듯, MCP 하나로 AI가 여러 서비스에 접근할 수 있게 된다.

MCP는 현재 AI 업계의 사실상 표준으로 자리잡았다. 2025년 3월 OpenAI가 공식 채택했고, 같은 해 12월에는 Anthropic이 MCP를 Linux Foundation 산하 Agentic AI Foundation에 기부하면서 OpenAI, Google, Microsoft, AWS 등이 공동으로 참여하는 공식 오픈소스 프로젝트가 됐다.

---

## PlayMCP의 핵심 기능

PlayMCP가 제공하는 가치는 크게 두 가지로 나뉜다. 일반 사용자를 위한 **도구함**, 개발자를 위한 **MCP 서버 등록 및 테스트 환경**이다.

### 도구함: AI에게 카카오 서비스 접근 권한 부여하기

도구함은 PlayMCP의 핵심 기능이다. 사용자가 원하는 MCP 도구를 선택해 한곳에서 관리하고, 이를 ChatGPT나 Claude 같은 외부 AI 서비스에서 사용할 수 있게 해준다.

현재 테스트용으로 공개된 카카오 MCP 서버는 다음과 같다.

| 서비스 | 가능한 요청 예시 |
| --- | --- |
| 카카오톡 나와의 채팅방 | "방금 알려준 내용 나와의 채팅방에 보내줘" |
| 톡캘린더 | "오늘 내 일정 알려줘" |
| 카카오맵 | "집에서 회사까지 경로 알려줘" |
| 선물하기 | "내가 받은 선물 목록 보여줘" |
| 멜론 | "작년 오늘 들은 노래 다시 틀어줘" |

**핵심은 '카카오 계정 인증 한 번'이다.** 개별 도구마다 인증할 필요 없이, 한 번의 로그인으로 도구함에 담긴 모든 MCP 도구를 사용할 수 있다.

### 개발자를 위한 플레이그라운드

개발자는 자신이 만든 MCP 서버를 PlayMCP에 등록하고, 실제 AI 대화에서 어떻게 작동하는지 테스트할 수 있다. 다른 개발자가 만든 MCP도 자유롭게 사용해볼 수 있어, 에이전틱 AI 생태계를 함께 실험하고 확장하는 플레이그라운드 역할을 한다.

## 실습: ChatGPT/Claude에서 PlayMCP 도구함 연동하기

### ChatGPT 연동

1. **PlayMCP 접속 및 로그인**  
   playmcp.kakao.com에 접속해 카카오 계정으로 로그인한다.
2. **도구함 구성**  
   원하는 MCP 도구(카카오톡, 멜론, 캘린더 등)를 도구함에 추가한다.
3. **ChatGPT 개발자 모드 설정**  
   ChatGPT에서 '개발자 모드'를 선택한 후, 맞춤형 MCP 서버 URL을 등록한다.
4. **도구함 인증**  
   카카오 계정으로 도구함을 인증하면 연동이 완료된다.

### Claude 연동

1. **PlayMCP에서 도구함 구성**  
   동일하게 playmcp.kakao.com에서 도구함을 설정한다.
2. **Claude 설정 진입**  
   Claude에서 '설정'을 선택한다.
3. **커스텀 커넥터 연결**  
   '커스텀 커넥터'에서 PlayMCP 도구함을 연결하고 카카오 계정으로 인증한다.

연동이 완료되면 "오늘 일정 알려줘", "이 내용 나와의 채팅방에 저장해줘" 같은 요청을 AI가 직접 처리할 수 있게 된다.

## MCP Player 10 공모전: 개발자를 위한 기회

카카오는 오늘(2025년 12월 19일) MCP 개발 공모전 'MCP Player 10'을 공식 발표했다. PlayMCP를 활용해 창의적인 MCP 서버를 개발하는 공모전이다.

| 항목 | 내용 |
| --- | --- |
| 모집 기간 | 2026년 1월 18일까지 |
| 참여 자격 | 개발자 누구나 |
| 심사 기준 | 창의성, 편의성, 기술적 안정성 |
| 결과 발표 | 2026년 2월 3일 |

상금 규모는 총 2,100만원이다. 1등 1명에게 1,000만원, 2등 1명에게 300만원, 3등 8명에게 각 100만원이 카카오페이 포인트로 지급된다. 상금 외에도 카카오 서비스와의 협업 기회, 마케팅 지원 등이 제공된다.

참여 방법은 간단하다. PlayMCP에서 개발한 MCP 서버를 업로드하고, 전체 공개로 전환한 뒤 공모전 페이지에서 응모하면 된다.

## 마치며

- PlayMCP는 AI와 카카오 서비스를 연결하는 국내 최초 MCP 기반 개방형 플랫폼이다
- 도구함 기능으로 일반 사용자도 ChatGPT, Claude에서 카카오 서비스를 연동해 사용할 수 있다
- MCP Player 10 공모전(~2026.1.18)에 참여하면 상금과 카카오 협업 기회를 얻을 수 있다

**실전 팁:** 오늘 당장 playmcp.kakao.com에 접속해 도구함에 톡캘린더를 추가하고, Claude에서 "오늘 일정 알려줘"라고 말해보자.
