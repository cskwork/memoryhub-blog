AgentKit은 시각적 워크플로 설계(Agent Builder), 데이터/도구 연결 중앙 관리(Connector Registry), 채팅 UI 임베드(ChatKit), 평가(Evals), 강화 파인튜닝(RFT)까지 한 번에 제공하는 **에이전트 올인원 툴킷**입니다. 복잡한 오케스트레이션·프롬프트 튜닝·UI 개발 시간을 대폭 줄여 **더 빨리, 더 안정적으로** 프로덕션에 올릴 수 있습니다.

---

## 왜 AgentKit인가?

기존 에이전트 개발은 다음을 직접 엮어야 했습니다:

- 복잡한 오케스트레이션(버저닝 없음)
- 커스텀 커넥터와 수작업 평가 파이프라인
- 프롬프트 튜닝, 그리고 몇 주짜리 프런트엔드 작업

**AgentKit**은 이를 표준화된 빌딩 블록으로 묶어 **설계 → 임베드 → 평가/최적화**까지 한 흐름으로 제공합니다. 실제로 Klarna는 지원 티켓의 2/3를 처리하는 에이전트를, Clay는 세일즈 에이전트로 **10배 성장**을 달성했습니다.

---

## 핵심 구성요소와 효과

구성요소 / 핵심 기능 / 기대 효과

|  |  |  |
| --- | --- | --- |
| **Agent Builder** | 드래그앤드롭 노드로 멀티에이전트 로직 설계, 프리뷰 실행, 인라인 평가 설정, **완전한 버저닝** | 반복 주기 단축, 협업 용이(제품/법무/엔지 모두 같은 캔버스) |
| **Connector Registry** | ChatGPT와 API 전반의 데이터 소스/도구 연결을 **하나의 관리자 패널**에서 통합 관리. Dropbox/Google Drive/SharePoint/Teams 및 서드파티 MCP 포함 | 데이터 거버넌스 강화, 커넥터 재사용·중앙 관리 |
| **Guardrails** | PII 마스킹·탈옥(jailbreak) 탐지 등 **오픈소스 안전 레이어**, Python/JS 라이브러리 지원 | 안정성과 규정 준수 확보, 운영 리스크 감소 |
| **ChatKit** | 스트리밍/스레드/사고 과정 표시 등 복잡한 채팅 UI를 **짧은 시간에 임베드**, 테마/브랜드 커스텀 | 프런트엔드 개발 시간 절감(사례: Canva, 2주 → 1시간 내 통합) |
| **Evals(업데이트)** | **Datasets, Trace grading, 자동 프롬프트 최적화, 서드파티 모델 평가** | 정밀한 성능 측정·개선 루프 구축(사례: 정확도 30%↑, 개발 시간 50%↓) |
| **RFT(강화 파인튜닝)** | o4-mini GA, GPT-5 프라이빗 베타. **커스텀 툴 호출**·**커스텀 그레이더** 지원 | 특정 업무에 맞춘 추론/도구 사용 최적화 |

## Agent Builder: 복잡한 로직을 ‘보이는 설계’로

- **노드 기반**(Agent, 파일검색, Guardrails, MCP, 사용자 승인 등)으로 흐름을 연결
- **프리뷰 실행·인라인 평가·버저닝**으로 빠른 반복

**사례**

- Ramp: 바이어 에이전트를 “몇 달→몇 시간”으로, **반복 주기 70% 단축**
- LY Corporation: 멀티에이전트 워크플로를 **2시간 내** 구축·실행

---

## ChatKit: 에이전트형 대화 UI를 제품에 즉시

- 스트리밍 응답, 스레드 관리, “생각 과정 표시” 등 **에이전트 UX 필수요소**를 기본 제공
- 앱/웹 어디든 임베드, **브랜딩 커스텀** 용이
- **사례**: Canva는 개발자 커뮤니티용 지원 에이전트를 **1시간 내 통합**, 기존 대비 **2주 절감**
- HubSpot, Albertsons, Evernote, Taboola 등 다양한 도입 사례

---

## 평가(Evals) 업그레이드: 성능을 수치로 만들기

- **Datasets**: 빠른 평가지 구축 → 자동 그레이더·휴먼 라벨로 확장
- **Trace grading**: **엔드투엔드 워크플로** 평가·자동 채점으로 병목/취약점 pinpoint
- **자동 프롬프트 최적화**: 휴먼 피드백·그레이더 결과로 개선 프롬프트 자동 생성
- **서드파티 모델 지원**: OpenAI 플랫폼에서 타사 모델도 동일 기준으로 평가
- **사례**: Carlyle—멀티에이전트 실사 프레임워크 **개발 50% 단축**, **정확도 30%↑**

---

## RFT(강화 파인튜닝): 업무 맥락에 맞는 ‘도구 쓰는’ 추론

- **o4-mini**에서 GA, **GPT-5는 프라이빗 베타** 진행 중
- **Custom tool calls**: “언제 어떤 도구를 쓸지”를 학습해 **추론-행동 품질** 상승
- **Custom graders**: 용례별 중요 기준으로 모델 행동을 **정렬(align)**

---

## 실제 적용 분야(아이디어)

- **고객지원**: 분류→가드레일→지식검색→요약/답변까지 전 과정 자동화
- **세일즈/리서치**: 멀티에이전트 분업(수집/요약/검증/후속조치)로 속도·정확도 동시 향상
- **사내 지식 비서**: 문서 저장소·메신저·노코드 툴 연동, 접근권한/PII 가드 지원
- **온보딩/교육**: 대화형 가이드, 문서 질의응답, 진행도 추적 및 피드백 자동화

---

## 시작 가이드

1. **Agent Builder**로 템플릿 선택 또는 빈 캔버스 시작
2. **Connector Registry**에서 데이터 소스/도구 연결 설정(MCP 포함)
3. **Guardrails** 규칙(PII, jailbreak 등) 활성화
4. **ChatKit**으로 제품 내 채팅 위젯 임베드 및 테마 커스텀
5. **Evals**로 데이터셋 만들고 **Trace grading**으로 병목 파악 → **자동 프롬프트 최적화**
6. 필요 시 **RFT**로 도구 사용/채점 기준을 업무에 맞게 파인튜닝

## 마무리

**핵심 인사이트:**

에이전트의 성패는 “모델 성능”보다 **설계·데이터 연결·평가·UI**의 전 과정을 하나의 루프로 묶는 데 달려 있습니다. AgentKit은 이 루프를 기본값으로 제공합니다—지금 작은 템플릿 하나로 시작해, **측정 가능한 개선 루프**를 즉시 돌려보세요.
