```
  [0]      [-1]
   P  y  t  h  o  n
   |  |  |  |  |  |
  [0][1][2][3][4][5]
 [-6][-5][-4][-3][-2][-1]
```

파일 경로에서 확장자만 떼내거나, 로그에서 특정 부분만 추출하다가 인덱스 에러를 본 적 있나요? 문자열을 자르는 방법은 여러 가지지만, 상황에 따라 최적의 선택지가 다릅니다. 이 글을 읽으면 슬라이싱부터 split, partition까지 실무에서 바로 쓸 수 있는 패턴을 명확히 구분할 수 있습니다.

문자열을 자르는 방법은 상황에 따라 다르며, 인덱스 기반 슬라이싱, 구분자 기반 split, 패턴 매칭까지 각각의 용도가 명확합니다.

## 배경

파이썬에서 문자열 처리는 데이터 전처리, 파싱, 로그 분석 등 거의 모든 프로젝트에서 필수입니다. 하지만 초보자들은 슬라이싱 인덱스를 헷갈리거나, split과 partition의 차이를 모르고 비효율적인 코드를 작성하는 경우가 많습니다.

**주요 용어 정의**

| 용어 | 설명 | 예시 |
| --- | --- | --- |
| 슬라이싱 | 인덱스 범위로 문자열 추출 | `s[1:4]` |
| 인덱싱 | 특정 위치의 문자 하나 접근 | `s[0]` |
| split | 구분자로 문자열을 리스트로 분리 | `s.split(',')` |
| partition | 첫 번째 구분자 기준으로 3분할 | `s.partition(':')` |
| strip | 양쪽 공백이나 특정 문자 제거 | `s.strip()` |

## 핵심

> 문자열 슬라이싱은 `[start:end:step]` 문법으로 인덱스 범위를 지정하고, split은 구분자 기반으로 여러 조각을 생성하며, partition은 한 번만 분할합니다.

- **슬라이싱**: 위치 기반으로 정확한 범위를 자를 때 (예: 파일명에서 앞 3글자)
- **split**: 구분자가 여러 개일 때 모두 분리 (예: CSV 데이터 파싱)
- **partition**: 구분자가 처음 한 번만 등장할 때 (예: 도메인과 경로 분리)
- **정규표현식**: 복잡한 패턴 매칭 필요 시 (예: 날짜 형식 추출)

## 실습

### 1. 기본 슬라이싱 (Python 3.x)

```
# 양수 인덱스
text = "Python3.11"
print(text[0:6])    # Python (0부터 6 직전까지)
print(text[:6])     # Python (처음부터 6 직전까지)
print(text[6:])     # 3.11 (6부터 끝까지)

# 음수 인덱스 (뒤에서부터)
print(text[-4:])    # 3.11 (뒤에서 4개)
print(text[:-4])    # Python (뒤에서 4개 제외)

# 스텝 활용
print(text[::2])    # Pto.1 (2칸씩 건너뛰기)
print(text[::-1])   # 11.3nohtyP (역순)
```

**출력 결과:**

```
Python
Python
3.11
3.11
Python
Pto.1
11.3nohtyP
```

### 2. split 메서드 (구분자 기반)

```
# 기본 split (공백 기준)
log = "2025-10-28 ERROR database connection failed"
parts = log.split()  # ['2025-10-28', 'ERROR', 'database', 'connection', 'failed']

# 구분자 지정
csv_line = "apple,banana,orange"
fruits = csv_line.split(',')  # ['apple', 'banana', 'orange']

# maxsplit (분할 횟수 제한)
url = "https://example.com/blog/post/123"
protocol, rest = url.split('://', 1)  # ['https', 'example.com/blog/post/123']

# rsplit (오른쪽부터 분할)
path = "/home/user/documents/file.txt"
directory, filename = path.rsplit('/', 1)  # ['/home/user/documents', 'file.txt']
```

### 3. partition과 rpartition

```
# partition (첫 번째 구분자로만 3분할)
email = "user@example.com"
username, at, domain = email.partition('@')
# ('user', '@', 'example.com')

# rpartition (마지막 구분자로 3분할)
file_path = "data.backup.tar.gz"
name, dot, extension = file_path.rpartition('.')
# ('data.backup.tar', '.', 'gz')
```

### 4. strip 계열 메서드

```
# 공백 제거
messy = "  hello world  \n"
print(messy.strip())   # "hello world"
print(messy.lstrip())  # "hello world  \n"
print(messy.rstrip())  # "  hello world"

# 특정 문자 제거
url = "https://example.com/"
clean = url.strip('https:/').rstrip('/')  # "example.com"
```

### 5. 정규표현식 (복잡한 패턴)

```
import re

# 날짜 추출
text = "오늘은 2025-10-28이고 내일은 2025-10-29입니다"
dates = re.findall(r'\d{4}-\d{2}-\d{2}', text)
# ['2025-10-28', '2025-10-29']

# split (복수 구분자)
mixed = "apple;banana,orange:grape"
items = re.split(r'[;,:]', mixed)
# ['apple', 'banana', 'orange', 'grape']
```

## 모범사례/패턴 비교

| 패턴 | 장점 | 주의점 |
| --- | --- | --- |
| **슬라이싱 `[:]`** | 속도 빠름, 직관적 인덱스 접근 | 길이를 모르면 IndexError 위험, 하드코딩 주의 |
| **split()** | 구분자로 자동 분리, 가변 개수 처리 | 빈 문자열 처리 확인, maxsplit으로 성능 개선 가능 |
| **partition()** | 한 번만 분할, 항상 3개 반환 보장 | 구분자 없으면 `('원본', '', '')` 반환 |
| **strip()** | 양쪽 불필요 문자 제거, 데이터 정제 | 중간 공백은 제거 안됨, replace와 혼동 주의 |
| **정규표현식 re** | 복잡한 패턴 매칭, 유연한 분할 | 속도 느림, 간단한 경우 오버스펙 |

## 마치며

문자열을 자를 때는 고정 길이면 슬라이싱, 구분자가 명확하면 split, 한 번만 나누면 partition을 선택하세요. 정규표현식은 복잡한 패턴에만 사용하고, 인덱스 에러를 방지하려면 len() 체크나 음수 인덱스를 활용하세요. 실무에서는 "파일명과 확장자 분리할 땐 rpartition('.'), CSV 파싱엔 split(',')가 정석"이라고 기억하면 됩니다.
