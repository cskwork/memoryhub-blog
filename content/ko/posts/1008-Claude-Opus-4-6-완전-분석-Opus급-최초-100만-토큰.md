"더 똑똑한 AI가 나왔다"는 소식에 이제 무감각해진 분들이 많을 겁니다. 매달 쏟아지는 벤치마크 숫자들, 과연 체감할 수 있는 차이일까요? 그런데 이번은 조금 다릅니다. Anthropic이 2026년 2월 6일 공개한 Claude Opus 4.6은 단순히 점수가 올랐다는 수준이 아니라,

**AI가 작업을 수행하는 방식 자체가 달라졌다는 평가를 받고 있습니다.**

에이전트 코딩부터 100만 토큰 컨텍스트까지, 이 글에서 실무자 관점으로 낱낱이 파헤쳐 보겠습니다.

**한줄요약:** 결론부터 말하면, Claude Opus 4.6은 Opus급 최초로 100만 토큰 컨텍스트를 지원하면서도 에이전트 코딩, 추론, 검색, 실무 작업 전 영역에서 업계 최고 성능을 기록한 모델입니다.

## 배경

AI 모델 시장은 2025년 하반기부터 뚜렷한 패턴을 보여왔습니다. OpenAI의 GPT-5.2, Google의 Gemini 3 Pro, 그리고 Anthropic의 Claude Opus 4.5가 치열하게 1위를 주고받는 구도였습니다. 그런데 한 가지 아쉬운 점이 있었습니다.

Opus급 모델은 200K 토큰 컨텍스트 한계를 넘지 못했다는 것입니다.

긴 코드베이스를 다루는 개발자, 수백 페이지 문서를 분석하는 리서처에게 컨텍스트 길이는 곧 작업의 한계선이었습니다.

성능은 좋지만 긴 대화에서 "context rot", 즉 대화가 길어질수록 성능이 떨어지는 현상도 만연했습니다.

> Opus 4.6은 "가장 똑똑한 모델을 업그레이드한다"는 Anthropic의 선언 아래, 코딩 역량 강화와 100만 토큰 컨텍스트라는 두 마리 토끼를 동시에 잡은 모델입니다.

Anthropic은 자체 엔지니어들이 매일 Claude Code로 코딩하면서 새 모델을 먼저 테스트한다고 밝혔습니다.

"Claude로 Claude를 만든다(We build Claude with Claude)"는 표현 그대로, 실전 검증을 거친 모델이라는 점이 이전과 다릅니다.

## 핵심 성능: 숫자로 보는 Opus 4.6

말보다 숫자가 정직합니다. 주요 벤치마크 결과를 비교해 보겠습니다.

| 벤치마크 | 측정 영역 | Opus 4.6 | Opus 4.5 | GPT-5.2 | Gemini 3 Pro |
| --- | --- | --- | --- | --- | --- |
| Terminal-Bench 2.0 | 에이전트 코딩 | **65.4%** | 59.8% | 64.7% | 56.2% |
| SWE-bench Verified | 코드 수정 | 80.8% | **80.9%** | 80.0% | 76.2% |
| OSWorld | 에이전트 컴퓨터 사용 | **72.7%** | 66.3% | - | - |
| BrowseComp | 에이전트 검색 | **84.0%** | 67.8% | 77.9% | 59.2% |
| Humanity's Last Exam | 다학제 추론(도구 사용) | **53.1%** | 43.4% | 50.0% | 45.8% |
| GDPval-AA | 실무 지식 작업(Elo) | **1,606** | 1,416 | 1,462 | 1,195 |
| ARC AGI 2 | 새로운 문제 해결 | **68.8%** | 37.6% | 54.2% | 45.1% |
| GPQA Diamond | 대학원 수준 추론 | 91.3% | 87.0% | **93.2%** | 91.9% |
| MMMLU | 다국어 Q&A | **91.1%** | 90.8% | 89.6% | 91.8% |

여기서 눈여겨볼 지표가 몇 가지 있습니다.

**GDPval-AA Elo 1,606점.** 이 벤치마크는 금융, 법률 등 실제 경제적 가치가 있는 지식 노동 과제를 측정합니다. Opus 4.6은 GPT-5.2보다 약 144 Elo 포인트, 전작 Opus 4.5보다 190 포인트 앞섭니다.

Elo 144점 차이는 대략 70% 확률로 Opus 4.6이 더 높은 점수를 받는다는 뜻입니다.

**ARC AGI 2에서 68.8%.** 전작 대비 거의 두 배 가까운 도약입니다(37.6% -> 68.8%). 이 테스트는 학습 데이터에 없는 완전히 새로운 패턴을 추론하는 능력을 측정하기 때문에, 단순 암기가 아닌 진짜 추론 능력의 향상을 시사합니다.

**BrowseComp 84.0%.** 인터넷에서 찾기 어려운 정보를 찾아내는 능력인데, 2위 GPT-5.2(77.9%)를 큰 폭으로 앞섰습니다.

리서치 업무에 Claude를 활용하는 사용자에게 의미 있는 수치입니다.

## 100만 토큰 컨텍스트: 왜 중요한가

Opus급 모델에서 100만 토큰 컨텍스트는 이번이 처음입니다. 단순히 "더 긴 텍스트를 넣을 수 있다"는 의미가 아닙니다.

핵심은 긴 컨텍스트에서도 **성능이 유지되느냐**입니다.

MRCR v2라는 벤치마크가 있습니다. 방대한 텍스트 속에 숨겨진 정보(이른바 "바늘")를 찾아내는 테스트인데,

100만 토큰에서 8개의 바늘을 찾는 난이도에서 Opus 4.6은 76%를 기록했습니다.

같은 조건에서 Sonnet 4.5는 18.5%에 그쳤습니다.

Anthropic은 이를 "모델이 실제로 활용할 수 있는 컨텍스트 양의 질적 전환"이라고 표현했습니다.

실무적으로 이것은 수십 개 파일로 구성된 대규모 코드베이스를 통째로 읽고 수정하거나,

수백 페이지 분량의 법률 문서를 한 번에 분석하는 작업이 현실적으로 가능해졌다는 뜻입니다.

가격도 확인해야 합니다. 기본 200K 토큰까지는 기존과 동일한 $5/$25(입력/출력, 백만 토큰당)이고, 200K를 초과하는 경우 $10/$37.50으로 프리미엄 요금이 적용됩니다.

## 새로운 기능: 개발자가 알아야 할 것들

Opus 4.6과 함께 도입된 주요 기능을 정리합니다.

### ① Adaptive Thinking (적응형 사고)

기존에는 확장 사고(Extended Thinking)를 켜거나 끄는 이분법적 선택만 가능했습니다. 이제 모델이 **스스로 판단해서 깊이 사고할 시점을 결정**합니다. 단순한 질문에는 빠르게 답하고, 복잡한 문제에서만 깊이 추론하는 방식입니다.

### ② Effort 레벨 (4단계)

low, medium, high(기본값), max 네 단계로 조절할 수 있습니다. Anthropic은 Opus 4.6이 기본적으로 더 깊이 사고하는 경향이 있어서, 간단한 작업에서 과도한 추론이 느껴지면 medium으로 낮추라고 권장합니다. API에서 `/effort` 파라미터로 제어합니다.

### ③ Context Compaction (베타)

긴 대화나 에이전트 작업에서 컨텍스트 창이 가득 차는 문제를 해결합니다. 설정한 임계값에 도달하면 **이전 컨텍스트를 자동으로 요약하고 교체**하여, 한계에 부딪히지 않고 더 긴 작업을 수행할 수 있습니다.

### ④ Agent Teams (Claude Code, 리서치 프리뷰)

Claude Code에서 여러 에이전트를 팀으로 구성하여 병렬로 작업할 수 있습니다. 코드베이스 리뷰처럼 독립적이고 읽기 중심인 작업에 적합합니다. Shift+Up/Down 또는 tmux로 개별 서브에이전트를 직접 제어할 수 있습니다.

### ⑤ 128K 출력 토큰

최대 128K 토큰까지 한 번에 출력할 수 있어, 대규모 출력 작업을 여러 요청으로 나눌 필요가 줄었습니다.

### ⑥ Claude in PowerPoint (리서치 프리뷰)

Claude in Excel의 성능 개선과 함께, PowerPoint에서도 Claude를 사용할 수 있게 되었습니다. 레이아웃, 폰트, 슬라이드 마스터를 읽어서 브랜드 일관성을 유지하면서 프레젠테이션을 생성합니다. Max, Team, Enterprise 플랜에서 사용 가능합니다.

## 안전성: 성능 향상이 안전 후퇴를 의미하지 않는다

Opus 4.6에 대해 Anthropic은 역대 가장 포괄적인 안전성 평가를 실시했다고 밝혔습니다.

자동화된 행동 감사에서 기만, 아첨, 사용자 망상 조장, 오용 협력 등 부정렬 행동 비율이 전작 Opus 4.5와 동등하거나 더 낮았습니다.

동시에 과도한 거부(무해한 질문에 답하지 않는 현상) 비율은 최근 Claude 모델 중 가장 낮았습니다.

사이버 보안 능력이 강화된 만큼, 악용 가능성에 대비하여 6개의 새로운 사이버 보안 탐지 프로브를 개발했다는 점도 주목할 부분입니다.

동시에 오픈소스 소프트웨어의 취약점을 찾아 패치하는 방어적 활용도 가속화하고 있습니다.

## 가격 및 접근 방법

| 항목 | 내용 |
| --- | --- |
| API 모델 ID | `claude-opus-4-6` |
| 기본 가격(200K 이하) | 입력 $5 / 출력 $25 (백만 토큰당) |
| 1M 컨텍스트 프리미엄(200K 초과) | 입력 $10 / 출력 $37.50 (백만 토큰당) |
| 최대 출력 토큰 | 128K |
| 컨텍스트 창 | 1M (베타) |
| US-only 추론 | 1.1배 토큰 가격 |
| 사용 가능 플랫폼 | claude.ai, API, 주요 클라우드 플랫폼 |

가격이 전작과 동일하다는 점은 꽤 의미 있습니다. Opus 4.5 대비 성능은 크게 올랐지만, 동일한 $5/$25 가격 체계를 유지했습니다.

## 마치며

- Opus 4.6은 에이전트 코딩, 추론, 검색, 실무 작업 벤치마크에서 업계 최고 수준을 기록했으며, 특히 ARC AGI 2(68.8%)와 GDPval-AA(1,606 Elo)에서 경쟁 모델과 큰 격차를 보였습니다.
- Opus급 최초의 100만 토큰 컨텍스트, Adaptive Thinking, Agent Teams 등 실무 생산성을 높이는 기능들이 함께 도입되었습니다.
- 성능 향상이 안전성 후퇴 없이 이루어졌다는 점에서, "더 강한 모델은 더 위험하다"는 통념에 반하는 사례를 제시했습니다.
- 실전 팁: API를 사용한다면 먼저 effort 레벨을 medium과 high로 각각 테스트해보세요. 간단한 작업에서 medium을 쓰면 비용과 지연을 크게 줄일 수 있습니다.
