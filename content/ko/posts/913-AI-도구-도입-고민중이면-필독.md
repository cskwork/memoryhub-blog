### 1. 주요 모델 사용 후기 요약

- **GPT-5.1 (Thinking / Codex)**
  - 장점: 자료 조사(Deep Research), 보고서·문서 작성, 정책·기획 문서에 강함. GPT-5 대비 지시 이해와 할루시네이션이 줄어 안정적인 편. ([Tom's Guide](https://www.tomsguide.com/ai/gpt-5-1-is-here-7-prompts-to-test-openais-smarter-more-customizable-chatgpt?utm_source=chatgpt.com "GPT-5.1 is here - 7 prompts to test OpenAI's smarter, more customizable ChatGPT"))
  - 코딩: 특히 **GPT-5.1-Codex-Max**가 에이전트형 코딩에 강함. 대규모 레포지토리 리팩토링, 장시간 디버깅, 백엔드 위주의 full-agent 작업에서 좋은 결과를 보임. ([OpenAI](https://openai.com/index/gpt-5-1-codex-max/?utm_source=chatgpt.com "Building more with GPT-5.1-Codex-Max"))
- **Gemini 3 Pro (+ Nano Banana Pro)**
  - 장점: 최신 벤치마크 기준 가장 높은 수준의 추론·멀티모달 성능을 보이며, 프론트엔드·디자인·웹 UI 생성 등에서 강점. 이미지 인식·생성, 특히 텍스트가 포함된 이미지 품질이 뛰어남. ([blog.google](https://blog.google/products/gemini/gemini-3/?utm_source=chatgpt.com "A new era of intelligence with Gemini 3"))
  - 단점/특징: 프롬프트 방식·맥락에 민감해서, 원하는 품질을 얻으려면 프롬프트를 비교적 상세하게 써야 하는 경향이 있음. 낯선 도메인에서는 자신감 있는 오답이 나오는 경우가 있어 검증이 필요. 매우 뛰어나서 사용자 지시를 제대로 안따르는 경향이 있음.
- **Claude Sonnet 4.5 / Opus 4.1**
  - 장점: Claude Code와 결합했을 때 IDE·터미널에서의 “코파일럿형” 사용성이 매우 좋고, 자연어 설명·리뷰·문서화에 강함. 벤치마크 점수와 별개로 직접 개발 환경에서는 가장 좋은 agentic 성능을 보이고, 사용자와 상호작용하면서 작업이 가능함
  - 단점/특징: 최신 벤치마크 기준으로는 GPT-5.1, Gemini 3 Pro 대비 추론·에이전트 코딩 영역에서 우위가 줄어든 상태. 다만 전체적으로 여전히 상위권 모델이며, 안정적인 품질과 UX가 강점. ([16x Eval](https://eval.16x.engineer/blog/claude-vs-claude-api-vs-claude-code?utm_source=chatgpt.com "Claude, Claude API, and Claude Code: What's the Difference?"))

### 2. 현재 코딩 도구 UX 평가 (내부 테스트 기준)

- **사용성/UX 체감 순서 (개발팀 실사용 기준)**
  1. Claude Code
  2. Codex (GPT-5.1-Codex 계열)
  3. Gemini CLI
- **모델 지능/성능 (공개 벤치마크 + 실사용 체감 종합)**
  - 복합 추론·멀티모달 기준:
    - Gemini 3 Pro ≥ GPT-5.1 계열 > Claude Sonnet 4.5
  - 에이전트형 코딩 기준:
    - GPT-5.1-Codex-Max와 Gemini 3 Pro가 상위권, Sonnet 4.5는 안정적이지만 상대적 우위는 줄어든 상태. ([IT Pro](https://www.itpro.com/technology/artificial-intelligence/google-launches-flagship-gemini-3-model-and-google-antigravity-a-new-agentic-ai-development-platform?utm_source=chatgpt.com "Google blows away competition with powerful new Gemini 3 model"))
- **툴별 특징**
  - Claude Code:
    - Sub-agents, commands, hooks, plan mode, sandbox 등 고급 기능과 IDE/터미널 연계 기능이 풍부해 “개발 환경과 붙이기 좋은 코파일럿” 느낌. ([SDpower](https://blog.sd.idv.tw/en/?utm_source=chatgpt.com "Claude Code Hooks System and Migration Guide - SDpower"))
  - Gemini CLI / Code Assist:
    - 설치·시작은 간단하고, Google Antigravity·Flow·Whisk 등과 연계해 프론트엔드/디자인·영상 업무까지 한 번에 다루기 좋음. 기능은 현재 빠르게 추가되는 중. ([IT Pro](https://www.itpro.com/technology/artificial-intelligence/google-launches-flagship-gemini-3-model-and-google-antigravity-a-new-agentic-ai-development-platform?utm_source=chatgpt.com "Google blows away competition with powerful new Gemini 3 model"))
  - Codex (GPT-5.1 Codex 계열):
    - 컨텍스트 자동 압축(compaction)을 통해 장시간 에이전트 루프를 돌릴 수 있고, CLI·IDE·Cloud 전반에 일관된 경험을 제공. 백엔드/인프라·대규모 리팩토링에 특히 적합. ([OpenAI](https://openai.com/index/gpt-5-1-codex-max/?utm_source=chatgpt.com "Building more with GPT-5.1-Codex-Max"))

### 3. 구독 시나리오별 옵션 정리

#### 안 1. Google AI Ultra 1개 (family 공유) – 전사용 실험 플랜

- 구성
  - Google AI Ultra 1계정 + 가족공유(최대 5인)로 활용
  - 개발 2: Gemini CLI, Gemini Code Assist, Antigravity IDE, Jules 등
  - 기획 1: Gemini 3 Pro + Deep Research, NotebookLM, Project Mariner
  - 마케팅 1: Flow, Whisk, Nano Banana Pro, YouTube Premium
  - 관리자 1: 결제/관리용 계정
- 장점
  - 30TB 스토리지, Deep Research, Veo 3, Gemini Agent 등 Google 생태계 기능을 여러 부서가 함께 시험해 볼 수 있음. ([Google One](https://one.google.com/about/google-ai-plans/?utm_source=chatgpt.com "Google AI Plans with Cloud Storage"))
  - 초기 3개월 할인 기간 동안 상대적으로 저렴한 비용으로 PoC 가능. ([blog.google](https://blog.google/products/google-one/google-ai-ultra/?utm_source=chatgpt.com "Google announces AI Ultra subscription plan"))
- 단점/주의
  - 개인 Google 계정·family 구조를 전사 업무에 쓰는 것이 회사 보안·정책과 맞는지 별도 검토 필요.
  - Google Workspace(회사 G메일/드라이브)와는 별도 체계임.

#### 안 2. Claude 중심 도입 (Claude Pro/Max 5x 기반)

- 구성 예시
  - 개발팀 중심으로 Claude Pro N석 또는 Claude Max 5X Plan으로 (최대 4석 계정 공유) 도입
  - Claude Code를 전원에게 배포해 IDE/터미널 코파일럿으로 활용
  - 기획팀 및 일반 사용자는 기본 클로드 웹 앱 사용
- 장점
  - Claude Code UX가 매우 좋고, **Skills/MCP**·문서 분석·스프레드시트 처리 등 비개발 업무까지 커버 가능. ([16x Eval](https://eval.16x.engineer/blog/claude-vs-claude-api-vs-claude-code?utm_source=chatgpt.com "Claude, Claude API, and Claude Code: What's the Difference?"))
  - Deep Research, Google Workspace/Office 365 연동 등 “업무 비서형” 활용도가 높음.
- 단점
  - 공식 요금제 기준 좌석당 비용이 발생하므로, 8인 기준으로는 Google AI Ultra family 공유 대비 비용이 커질 수 있음.
  - 멀티모달(이미지/영상 생성)은 별도 툴과 병행해야 함. (mcp)

#### 안 3. ChatGPT Business (Codex) – 백엔드/리서치 최적화

- 구성
  - ChatGPT Business 최소 2석 이상 (개발자/기획자 중심) ([OpenAI Help Center](https://help.openai.com/en/articles/11481834-chatgpt-rate-card?utm_source=chatgpt.com "ChatGPT Rate Card (Business, Enterprise/Edu)"))
  - Codex CLI/IDE를 개발자 전원이 사용(Plus/Pro/Business 권한이 있는 사람 기준) ([OpenAI Developers](https://developers.openai.com/codex/models/?utm_source=chatgpt.com "Codex Models"))
- 장점
  - GPT-5.1(Thinking/Instant) + GPT-5.1-Codex-Max 조합으로,
    - 백엔드·인프라·데이터 파이프라인 등 “하드한 코딩 업무”에 매우 강함. ([Composio](https://composio.dev/blog/kimi-k2-thinking-vs-claude-4-5-sonnet-vs-gpt-5-codex-tested-the-best-models-for-agentic-coding?utm_source=chatgpt.com "GPT-5.1 Codex vs. Claude 4.5 Sonnet vs. Kimi K2 Thinking"))
  - ChatGPT Deep Research 기능은 현재 상용 중에서 가장 성숙한 수준의 리서치 에이전트에 가까움. ([WIRED](https://www.wired.com/story/openai-launches-an-agentic-web-based-coding-tool?utm_source=chatgpt.com "OpenAI Launches an Agentic, Web-Based Coding Tool"))
  - Sora 2(영상), GPT-계열 이미지 모델까지 포함하여 멀티미디어 생성도 가능. ([OpenAI](https://openai.com/index/sora-2/?utm_source=chatgpt.com "Sora 2 is here"))
- 단점
  - 이미지/영상 생성 품질은 Nano Banana Pro·Veo 3 계열과 비교해 도메인에 따라 우열이 갈릴 수 있어, 디자인/마케팅 용도로는 Google 쪽 조합이 더 매력적일 수 있음. ([Android Central](https://www.androidcentral.com/apps-software/ai/nano-banana-goes-pro-with-refined-design-consistency-and-accuracy-in-the-gemini-app?utm_source=chatgpt.com "Nano Banana goes Pro with refined design consistency and accuracy in the Gemini app"))

### 4. 최종 추천 방향(요약)

- **개발 관점**
  - 백엔드·인프라·대규모 리팩토링: **ChatGPT Business - Codex (GPT-5.1-Codex-Max)**
  - 프론트엔드·디자인·웹앱: **Gemini 3 Pro + Gemini CLI (현재 Ultra Plan에서만 Gemini3 사용 가능) /Antigravity**
  - **IDE/터미널 기반 코파일럿 및 예측 가능한 안정적이고 균형잡힌 풀 스택 코딩: Claude Code**
- **비개발 업무 관점**
  - 기획·리서치·보고서: GPT-5.1 Deep Research, Claude Deep Research 병행
  - 마케팅/디자인: Google AI Ultra(또는 AI Pro) 기반 Nano Banana Pro, Flow, Whisk 활용
- **현실적인 도입 1차안 제안**
  - **① 전사 PoC: 개발팀 핵심 인원 4 - 8명에게 Claude Pro Max 5x 계정 2개 제공. (1인 4 계정)**
  - ② 병행 PoC: Google AI Pro 또는 Ultra 1계정(family 5인) 또는 ChatGPT Business(Codex) 3개월간 다부서 파일럿.
  - ③ 3개월 후 실제 사용량·만족도·보안/정책 이슈를 기준으로 “정식 좌석제(Claude Team은 - Premium만 Claude Code 사용 가능 / ChatGPT Business 다석) + 필요시 Google AI Pro/Ultra” 형태로 재설계
