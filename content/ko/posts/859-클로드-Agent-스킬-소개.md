Claude 앱에서 스킬이 스프레드시트나 프레젠테이션 같은 파일을 만드는 걸 이미 보셨을 거예요. 이제는 직접 스킬을 만들어서 Claude 앱, Claude Code, API 전체에서 사용할 수 있습니다.

**스킬 작동 방식**  
Claude는 작업을 하면서 사용 가능한 스킬을 스캔해서 관련된 걸 찾아요. 매칭되는 스킬을 찾으면 필요한 최소한의 정보와 파일만 불러오기 때문에, 전문 지식에 접근하면서도 빠른 속도를 유지할 수 있죠.

스킬의 특징:

- **조합 가능**: 스킬을 여러 개 겹쳐 쓸 수 있어요. Claude가 자동으로 필요한 스킬을 파악해서 조율합니다.
- **이식 가능**: 어디서나 같은 형식을 사용해요. 한 번 만들면 Claude 앱, Claude Code, API 전체에서 쓸 수 있습니다.
- **효율적**: 필요한 것만 필요할 때 불러와요.
- **강력함**: 기존 프로그래밍이 토큰 생성보다 더 안정적인 작업을 위해 실행 가능한 코드를 포함할 수 있어요.

스킬은 전문 지식을 패키지화할 수 있는 맞춤형 온보딩 자료라고 생각하면 돼요. Claude가 여러분에게 가장 중요한 분야의 전문가가 될 수 있게 해주죠. Agent Skills 디자인 패턴, 아키텍처, 개발 모범 사례에 대한 기술적인 심층 내용은 엔지니어링 블로그에서 확인하세요.

**모든 Claude 제품에서 스킬 사용하기**

**Claude 앱**  
Pro, Max, Team, Enterprise 사용자가 스킬을 사용할 수 있어요. 문서 작성 같은 일반적인 작업용 스킬, 커스터마이징 가능한 예시, 그리고 직접 만드는 커스텀 스킬을 제공합니다.

Claude가 작업에 따라 관련 스킬을 자동으로 실행해요. 수동으로 선택할 필요가 없습니다. Claude가 작업하는 동안 사고 과정에서 스킬을 사용하는 걸 볼 수도 있어요.

스킬 만들기는 간단해요. "skill-creator" 스킬이 대화형 가이드를 제공합니다. Claude가 워크플로우에 대해 질문하고, 폴더 구조를 생성하고, SKILL.md 파일 형식을 잡아주고, 필요한 리소스를 묶어줘요. 파일을 직접 편집할 필요가 없습니다.

설정에서 스킬을 활성화하세요. Team과 Enterprise 사용자의 경우, 관리자가 먼저 조직 전체에서 스킬을 활성화해야 해요.

**Claude 개발자 플랫폼 (API)**  
Agent Skills(보통 그냥 스킬이라고 부름)를 이제 Messages API 요청에 추가할 수 있고, 새로운 `/v1/skills` 엔드포인트로 커스텀 스킬 버전 관리를 프로그래밍 방식으로 제어할 수 있어요. 스킬은 Code Execution Tool 베타가 필요한데, 이게 스킬 실행에 필요한 보안 환경을 제공합니다.

Anthropic이 만든 스킬을 사용하면 Claude가 수식이 있는 전문 Excel 스프레드시트, PowerPoint 프레젠테이션, Word 문서, 작성 가능한 PDF를 읽고 생성할 수 있어요. 개발자는 특정 사용 사례에 맞춰 커스텀 스킬을 만들어 Claude의 기능을 확장할 수 있습니다.

Claude Console에서 스킬 버전을 쉽게 만들고, 확인하고, 업그레이드할 수도 있어요.

자세한 내용은 문서나 Anthropic Academy를 참고하세요.

**Claude Code**  
스킬로 Claude Code에 팀의 전문성과 워크플로우를 추가할 수 있어요. anthropics/skills 마켓플레이스의 플러그인을 통해 스킬을 설치하세요. Claude가 관련성이 있을 때 자동으로 불러옵니다. 버전 관리를 통해 팀과 스킬을 공유할 수 있어요. `~/.claude/skills`에 추가해서 수동으로 설치할 수도 있습니다. Claude Agent SDK도 커스텀 에이전트 구축을 위해 동일한 Agent Skills를 지원해요.

**시작하기**

- Claude 앱: 사용자 가이드 & 도움말 센터
- API 개발자: 문서
- Claude Code: 문서
- 커스터마이징 가능한 예시 스킬: GitHub 저장소

**앞으로의 계획**  
스킬 제작 워크플로우를 간소화하고 기업 전체 배포 기능을 개선해서, 조직이 팀 전체에 스킬을 더 쉽게 배포할 수 있도록 작업 중입니다.

참고로 이 기능은 Claude에게 코드 실행 권한을 부여해요. 강력하긴 하지만, 어떤 스킬을 사용할지 신중하게 선택해야 한다는 의미예요. 데이터 안전을 위해 신뢰할 수 있는 출처의 스킬만 사용하세요.
