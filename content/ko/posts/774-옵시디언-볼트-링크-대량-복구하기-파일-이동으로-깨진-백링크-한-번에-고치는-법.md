## ? 문제 상황

옵시디언을 사용하다 보면 폴더 구조를 정리하면서 파일들을 이동시키는 경우가 많습니다. 특히 초기에 만든 폴더 구조가 마음에 들지 않아 대대적인 정리를 할 때가 있죠.

저도 최근에 학습 자료들을 정리하면서 다음과 같은 변경을 했습니다:

- **기존**: `Resources/학습자료/중요자료/`
- **새로운**: `30_Resources/14_Learning/중요자료/`

문제는 파일은 이동했지만 **175개가 넘는 백링크들이 모두 깨졌다**는 것이었습니다! ?

## ? 깨진 링크 패턴 분석

깨진 링크들은 크게 두 종류였습니다:

### 1. 일반 백링크

```
[[Resources/학습자료/중요자료/네트워크/스위치]]
```

### 2. 이미지 임베드

```
![[Resources/학습자료/중요자료/attachments/이미지.png]]
```

하나하나 수동으로 고치기에는 너무 많은 양이었고, 더 효율적인 방법이 필요했습니다.

## ?️ 해결 과정

### 1단계: 문제 파악

먼저 어떤 파일들이 영향을 받았는지 확인했습니다.

```
# 깨진 링크가 있는 파일 찾기
find . -name "*.md" -type f -exec grep -l "Resources/학습자료" {} \;
```

### 2단계: 백업 생성 (중요!)

대량 수정 전 반드시 백업을 만들어야 합니다.

```
# Git으로 현재 상태 커밋하거나 폴더 전체 복사
cp -r "볼트폴더" "볼트폴더_백업"
```

### 3단계: 일괄 링크 수정

**핵심 명령어**입니다. 이 한 줄로 대부분의 문제를 해결했습니다:

```
# 명령어 해석 포함 
# `find . -name "*.md" -type f`: 현재 폴더에서 모든 마크다운 파일 찾기
# sed -i '' 명령어로 파일 내용 직접 수정
# - `|` 구분자 사용: 경로에 `/`가 많아서 `|`를 구분자로 사용
find . -name "*.md" -type f -exec sed -i '' 's|Resources/학습자료/|30_Resources/14_Learning/|g' {} \;
```

### 4단계: 상대 경로 문제 해결

일부 파일에서 상대 경로 참조도 발견했습니다:

```
![[../attachments/이미지.png]]
```

이런 경우는 개별적으로 절대 경로로 변경했습니다:

```
![[30_Resources/14_Learning/중요자료/attachments/이미지.png]]
```

## ✅ 결과 확인

### 수정 완료 확인

```
# 기존 패턴이 남아있는지 확인
find . -name "*.md" -exec grep -l "Resources/학습자료" {} \;

# 새로운 패턴으로 잘 바뀌었는지 확인
find . -name "*.md" -exec grep -c "30_Resources/14_Learning" {} \; | awk '{s+=$1} END {print "수정된 링크 수: " s}'
```

### ? 유용한 검증 명령어

```
# 특정 패턴 검색
grep -r "찾을패턴" .

# 링크 개수 세기
find . -name "*.md" -exec grep -c "\[\[.*\]\]" {} \; | awk '{s+=$1} END {print s}'

# 빈 링크 찾기 - find 명령어로 모든 마크다운 파일 검색
find . -name "*.md" -exec grep -l "\[\[\]\]" {} \;
```

## ? 마무리

옵시디언의 강력한 백링크 시스템을 제대로 활용하려면 이런 대량 수정 기법을 알아두는 것이 중요합니다. 특히 볼트가 커질수록 수동 작업은 현실적으로 불가능하죠.

**? Pro Tip**: 대규모 폴더 구조 변경 전에는 항상 Git으로 버전 관리를 하거나, 볼트 전체를 백업해두세요. 안전이 최우선입니다!
