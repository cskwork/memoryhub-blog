"회의록 작성하려고 녹음 파일을 클라우드에 올렸는데, 민감한 정보가 담겨 있어서 찜찜했던 적 있으신가요?" 음성-텍스트 변환(STT) 기술은 분명 편리하지만, 대부분의 서비스가 내 음성 데이터를 서버로 전송한다는 사실은 잘 알려져 있지 않습니다. 오늘 소개할 Handy는 이 문제를 정면으로 해결합니다.

**완전히 오프라인으로 동작하면서도 클라우드급 정확도를 제공하는 무료 오픈소스 STT 데스크톱 앱**입니다.

**한줄요약:** 결론부터 말하면, Handy는 Whisper와 Parakeet 모델을 로컬에서 실행해 프라이버시를 완벽히 보장하면서도 실용적인 음성 입력을 가능하게 하는 크로스 플랫폼 앱이다.

---

## 배경

음성 인식 기술의 접근성이 크게 높아졌습니다. 스마트폰 음성 검색부터 회의록 자동 작성, 자막 생성까지 STT는 일상과 업무 곳곳에 스며들었습니다. 하지만 대부분의 STT 서비스에는 간과하기 쉬운 조건이 붙습니다.

**첫째**, 인터넷 연결이 필수입니다. 클라우드 서버가 실제 음성 처리를 담당하기 때문입니다.

**둘째**, 내 음성 데이터가 외부 서버를 거칩니다. 개인 정보, 회사 기밀,

민감한 대화 내용이 제3자 인프라에 전송된다는 의미입니다.

**셋째**, 무료 플랜에는 제약이 따릅니다. 월 사용량 제한, 기능 제한, 이후 유료 전환 유도가 일반적입니다.

> 한 줄 정의: STT(Speech-to-Text)란 사람의 음성을 인식해 텍스트로 변환하는 기술로, 음성 비서, 자막 생성, 회의록 작성 등에 활용된다.

2022년 OpenAI가 Whisper 모델을 오픈소스로 공개하면서 상황이 달라졌습니다.

68만 시간의 다국어 음성 데이터로 학습된 이 모델은 상업 서비스에 견줄만한 정확도를 보여주었고, 누구나 로컬 환경에서 실행할 수 있게 되었습니다. 문제는 일반 사용자가 Python 환경을 구축하고 명령어를 다루기가 쉽지 않다는 점이었습니다.

**Handy는 바로 이 간극을 메웁니다.**

Whisper와 NVIDIA의 Parakeet 모델을 사용자 친화적인 데스크톱 앱으로 포장해, 기술적 배경 없이도 로컬 STT의 혜택을 누릴 수 있게 합니다.

## Handy 핵심 특징

Handy의 작동 방식은 단순합니다. 단축키를 누르고, 말하고, 손을 떼면 텍스트가 자동으로 입력됩니다. 이 과정이 전부 내 컴퓨터 안에서 완결됩니다.

**완전한 오프라인 동작**이 가장 큰 장점입니다. 인터넷 연결 없이 동작하므로 비행기 안에서도,

보안이 엄격한 환경에서도 사용할 수 있습니다.

음성 데이터가 외부로 전송되지 않으니 기업 기밀 회의나 의료 상담 내용도 안심하고 변환할 수 있습니다.

**다양한 모델 선택지**를 제공합니다. Whisper 계열(Small, Medium, Turbo, Large)과 Parakeet V3 중에서 환경에 맞게 고를 수 있습니다. Whisper는 GPU 가속을 활용해 빠른 처리가 가능하고, Parakeet V3는 CPU만으로도 실시간의 약 5배 속도로 변환합니다. GPU가 없는 노트북 사용자라면 Parakeet이 현실적인 선택입니다.

**크로스 플랫폼 지원**도 빼놓을 수 없습니다. macOS(Intel, Apple Silicon), Windows, Linux에서 모두 동작합니다.

Tauri 프레임워크를 기반으로 하여 Electron 대비 훨씬 가벼운 용량과 빠른 실행 속도를 자랑합니다.

**Push-to-Talk 방식**의 인터페이스가 직관적입니다. 설정한 단축키를 누르는 동안만 녹음이 진행되고, 손을 떼면 자동으로 변환이 시작됩니다. Silero 기반 음성 활동 감지(VAD)가 묵음 구간을 자동으로 제거해 불필요한 처리를 줄입니다.

## 주요 STT 도구 비교

"로컬 STT가 클라우드만큼 좋을까?"라는 의문이 들 수 있습니다.

현재 시점에서 주요 STT 도구들을 비교해보면 Handy의 위치가 명확해집니다.

| 도구 | 처리 방식 | 비용 | 프라이버시 | 한국어 지원 | 특징 |
| --- | --- | --- | --- | --- | --- |
| Handy | 로컬(오프라인) | 무료 | 완전 보장 | Whisper 모델 지원 | 오픈소스, 데스크톱 앱 |
| OpenAI Whisper API | 클라우드 | 분당 $0.006 | 서버 전송 | 우수 | 최고 수준 정확도 |
| 네이버 클로바노트 | 클라우드 | 월 300분 무료 | 서버 전송 | 최적화 | 화자 분리, 한국어 특화 |
| Google Cloud STT | 클라우드 | 월 60분 무료 후 과금 | 서버 전송 | 지원 | 125개 언어, 기업용 |
| Microsoft Dictate | 클라우드 | Office 365 포함 | 서버 전송 | 지원 | Office 앱 통합 |
| Google Docs 음성입력 | 클라우드 | 무료 | 서버 전송 | 지원 | 브라우저 내 실시간 |

클라우드 서비스들은 분명 편리합니다. 별도 설치 없이 웹에서 바로 사용할 수 있고,

서버의 강력한 컴퓨팅 파워를 활용합니다. 네이버 클로바노트처럼 한국어에 특화된 서비스도 있습니다.

그러나 **데이터 주권 관점에서 로컬 처리의 가치**는 분명합니다.

의료, 법률, 금융 분야처럼 민감 정보를 다루는 환경에서는 데이터가 외부 서버를 거치는 것 자체가

규정 위반이 될 수 있습니다.

프리랜서나 1인 기업가에게는 월정액 부담 없이 무제한 사용이 가능하다는 점도 매력적입니다.

**정확도 측면**에서 Whisper Large V3는 7.4%의 평균 단어 오류율(WER)을 기록합니다. 이는 상용 클라우드 서비스와 동등한 수준입니다. 영어, 스페인어, 프랑스어, 독일어 등 주요 언어에서 특히 강점을 보이며,

한국어도 실용적인 수준으로 지원합니다.

## 실습: Handy 설치와 첫 사용

### 1단계: 다운로드 및 설치

Handy 공식 사이트(handy.computer) 또는 GitHub 릴리스 페이지에서 운영체제에 맞는 설치 파일을 받습니다.

macOS는 .dmg, Windows는 .msi, Linux는 .AppImage 형식입니다. 설치 후 첫 실행 시 마이크 접근 권한과 접근성 권한을 요청하는데, 단축키로 시스템 전역에서 동작하려면 이 권한이 필수입니다.

### 2단계: 모델 선택

Settings에서 사용할 모델을 선택합니다. 처음이라면 모델 다운로드가 필요합니다. 권장 선택 기준은 다음과 같습니다.

GPU가 있는 데스크톱이라면 Whisper Medium 또는 Turbo가 속도와 정확도의 균형이 좋습니다. CPU만 사용하는 노트북이라면 Parakeet V3가 최선입니다. 빠른 테스트를 원한다면 Whisper Small로 시작해볼 수 있습니다.

### 3단계: 단축키 설정

기본 단축키를 확인하거나 자신에게 편한 조합으로 변경합니다.

macOS에서는 Globe 키 지원이 개발 중이며, 현재는 Cmd 조합이 일반적입니다.

### 4단계: 첫 변환 테스트

텍스트 입력이 가능한 아무 앱(메모장, 브라우저 검색창 등)을 열고, 설정한 단축키를 누른 채 말합니다.

손을 떼면 잠시 후 변환된 텍스트가 커서 위치에 입력됩니다.

**참고:** 프록시 환경이나 네트워크 제한이 있어 자동 다운로드가 안 되는 경우, 모델 파일을 수동으로 받아 앱 데이터 디렉터리의 models 폴더에 넣을 수 있습니다. Settings의 About 섹션에서 정확한 경로를 확인할 수 있습니다.

## 사용 시나리오별 추천

| 시나리오 | 추천 도구 | 이유 |
| --- | --- | --- |
| 기업 기밀 회의록 | Handy | 데이터 외부 전송 없음, 규정 준수 |
| 한국어 인터뷰 전사 | 네이버 클로바노트 | 한국어 최적화, 화자 분리 |
| 일상적 메모/검색 | Google Docs 음성입력 | 별도 설치 불필요, 즉시 사용 |
| 대량 파일 일괄 처리 | OpenAI Whisper API | 안정적인 대규모 처리 |
| 오프라인 환경 작업 | Handy | 인터넷 불필요 |
| Office 문서 작성 | Microsoft Dictate | 앱 내 통합, 즉시 반영 |

단일 도구가 모든 상황에 최적일 수는 없습니다.

프라이버시와 비용이 우선이라면 Handy, 한국어 정확도가 최우선이라면 클로바노트,

편의성이 중요하다면 클라우드 서비스도 각각 합리적인 선택입니다.

## 마치며

- Handy는 Whisper와 Parakeet 모델을 로컬에서 실행해 완전한 오프라인 STT를 제공합니다.
- 무료이면서 오픈소스이므로 비용 부담 없이 무제한 사용이 가능하고, 필요에 따라 확장할 수 있습니다.
- 클라우드 서비스 대비 프라이버시가 완벽히 보장되어 민감 정보를 다루는 환경에 적합합니다.

실전 팁: 오늘 당장 handy.computer에서 앱을 받아 Parakeet V3 모델로 첫 음성 변환을 테스트해보세요.

GPU 없이도 실용적인 속도를 경험할 수 있습니다.
