### ⚠️ MCP Security Issues Identified

*April-July 2025 | Security research*

Prompt injection, tool permission issues, lack of authentication found in ~2,000 public MCP servers. June 2025 spec added OAuth.

**Why it matters:** Security critical for MCP implementations. Public servers without auth leak sensitive data.

**Action:** Audit your MCP servers against June 2025 spec. Implement OAuth. Never expose publicly without authentication.
