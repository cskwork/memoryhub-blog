# 

ChatGPT와 대화할 때 이런 경험 있으신가요? 몇 번 대화하다 보면 앞서 말한 내용을 까먹어서 다시 설명해야 하는 상황 말이에요. 저도 프로젝트 관리 AI 봇을 만들면서 같은 문제에 부딪혔습니다. 사용자가 "지난번에 말한 그 기능" 이라고 하면 AI는 영문을 모르겠다는 듯이 다시 처음부터 물어봐야 했거든요.

그런데 최근 Zep에서 공개한 **Graphiti**라는 오픈소스가 이 문제를 완전히 다른 방식으로 해결하고 있어서 깜짝 놀랐습니다. 단순히 대화 내용을 저장하는 게 아니라, 시간의 흐름에 따라 변화하는 관계와 사실들을 **지식 그래프**로 구축한다는 발상이 정말 혁신적이더라고요.

⚡ **TL;DR**: Graphiti는 AI 에이전트가 시간에 따라 변화하는 정보를 기억하고 추론할 수 있게 해주는 오픈소스 프레임워크입니다. 단순한 대화 저장을 넘어서 관계와 사실의 변화를 추적해 더 똑똑한 AI를 만들 수 있어요.

## 1. 배경: 왜 지금 시간적 지식 그래프인가?

기존 RAG(Retrieval-Augmented Generation) 방식은 배치 처리와 정적 데이터 요약에 의존해서 자주 변경되는 데이터에는 비효율적입니다. 예를 들어 고객 서비스 AI가 있다고 해보세요. 고객의 취향이 바뀌었거나, 구독 상태가 변경되었을 때 기존 방식으로는 전체 데이터를 다시 처리해야 했어요.

Microsoft의 GraphRAG가 텍스트 청킹을 그래프로 확장했지만, 정적 문서용으로 설계되어 시간적 측면을 다루지 못한다는 한계가 있었습니다.

**Graphiti가 해결하는 핵심 문제들:**

✅ **실시간 업데이트**: 배치 재계산 없이 새로운 데이터 즉시 통합  
✅ **양방향 시간 모델**: 사건 발생 시간과 입력 시간을 별도 추적  
✅ **하이브리드 검색**: 의미적 임베딩, 키워드(BM25), 그래프 탐색을 결합

## 2. 핵심 개념 정리

> **시간적 지식 그래프(Temporal Knowledge Graph)**  
> 엔티티 간의 관계가 시간에 따라 어떻게 변화하는지를 추적하고 기록하는 지식 구조

Graphiti는 세 가지 수준의 하위 그래프로 구성됩니다: Episode Subgraph(원시 입력 데이터), Entity Subgraph(추출된 엔티티), 그리고 이들 간의 관계를 나타내는 구조입니다.

**핵심 구성 요소:**

**에피소드(Episode)**: 원시 데이터 단위 (메시지, JSON, 텍스트)

- 비손실 데이터 스토어 역할
- 시간 스탬프와 함께 저장

**엔티티(Entity)**: 사람, 장소, 개념 등

- "김민수", "서울", "프로젝트 A" 같은 구체적 객체

**관계(Edge)**: 엔티티 간 연결

- "김민수는 서울에 거주한다"
- 시간적 메타데이터 포함 (valid\_at, invalid\_at)

```
# 간단한 팩트 예시
fact = "김민수는 마케팅 팀장이다"
# 시간이 지나서...
updated_fact = "김민수는 개발 팀장이다"
# → Graphiti는 이런 변화를 자동으로 추적!
```

## 3. 실습: Graphiti 동작 원리

**① 설치 및 설정**

Neo4j 데이터베이스와 OpenAI API 키가 필요합니다. 가장 간단한 방법은 Neo4j Desktop을 사용하는 것이에요.

```
# 기본 설치
pip install graphiti-core

# 다양한 LLM 지원
pip install graphiti-core[anthropic,groq,google-genai]
```

**② 데이터 입력과 그래프 구축**

Graphiti는 비구조화된 텍스트와 구조화된 데이터를 모두 처리해서 시간, 전체 텍스트, 의미 검색, 그래프 알고리즘을 결합한 쿼리가 가능합니다.

**③ 검색과 추론**

100ms 이내의 빠른 검색 속도로 의미적, 키워드, 그래프 기반 검색을 모두 지원해요.

## 4. 모범 사례와 활용 분야

Graphiti는 영업, 고객 서비스, 건강, 금융 등 다양한 분야에서 장기 기억과 상태 기반 추론을 가능하게 합니다.

활용 분야 장점 구체적 사례

|  |  |  |
| --- | --- | --- |
| **개인화 어시스턴트** | 사용자 상호작용 학습 | 취향 변화 추적, 개인 맞춤 추천 |
| **고객 서비스** | 문맥 유지 대화 | 이전 문의 이력, 해결 과정 기억 |
| **영업 지원** | 고객 관계 추적 | 구매 이력, 선호도 변화 모니터링 |
| **프로젝트 관리** | 상태 변화 추적 | 진행 상황, 담당자 변경 기록 |

**실제 성과**: Deep Memory Retrieval (DMR) 벤치마크에서 기존 시스템인 MemGPT를 능가하는 성능을 보였습니다.

**주목할 만한 특징들:**

? **스마트 그래프 업데이트**: 새로운 엔티티를 기존 그래프와 자동 비교해 최신 컨텍스트 반영  
? **풍부한 엣지 의미**: 인간이 읽기 쉬운 의미적 표현으로 검색 성능과 해석 가능성 향상  
⚡ **성능 최적화**: 검색 결과가 보통 100ms 이내로 나오며, 지연 시간은 주로 써드파티 임베딩 API 호출에 의해 결정

## 5. 마치며

Graphiti를 살펴보면서 AI 메모리의 패러다임이 어떻게 바뀌고 있는지 확실히 느꼈습니다. 단순히 대화를 저장하는 수준을 넘어서 관계의 변화와 시간의 흐름을 이해하는 AI가 가능해진 거예요. 데이터가 변화하는 과정을 시간에 따라 추적할 수 있는 기능과 하이브리드 검색, 확장 가능한 데이터 처리가 핵심이죠.

특히 13.4k GitHub 스타를 8개월 만에 달성하고 35명 이상의 기여자와 주간 2만 5천 PyPI 다운로드라는 성장세를 보면, 개발자들이 얼마나 이런 기술을 기다려왔는지 알 수 있어요.

실제 프로젝트에 적용할 때는 Neo4j 설정과 LLM API 비용을 고려해서 점진적으로 시작해보시길 추천드립니다.
