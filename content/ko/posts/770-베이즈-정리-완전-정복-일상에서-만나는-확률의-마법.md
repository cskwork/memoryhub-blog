## ? 베이즈 정리가 뭔가요?

**베이즈 정리는 새로운 정보를 얻었을 때, 기존 생각을 얼마나 바꿔야 하는지 수학적으로 계산해주는 공식**입니다.

### ? 핵심 공식

```
P(A|B) = P(B|A) × P(A) / P(B)
또는
사후확률 = (가능도 × 사전확률) / 전체확률
```

---

## ? 스마트폰 속 베이즈 정리

### 스팸 메일 필터링 (정확한 계산)

단어 정상 메일 출현율 스팸 메일 출현율 판정 기여도

|  |  |  |  |
| --- | --- | --- | --- |
| "무료" | 2% | 85% | ? 강력한 스팸 신호 |
| "할인" | 15% | 70% | ⚠️ 중간 스팸 신호 |
| "안녕하세요" | 80% | 10% | ✅ 정상 신호 |

**실제 계산 예시** (가정: 전체 메일 중 스팸 비중 5%)

메일에 "무료"와 "할인"이 함께 있다면:

- **우도비(Likelihood Ratio)**: (0.85×0.70)/(0.02×0.15) ≈ 198
- **사전 오즈**: 0.05/0.95 ≈ 0.053
- **사후 오즈**: 0.053 × 198 ≈ 10.5
- **최종 스팸 확률**: 약 **91%**

? **중요**: 베이스레이트(스팸 비중)가 10%면 96%, 1%면 67%로 달라집니다!

## ? 의료진단에서의 베이즈 정리 (정확한 용어 사용)

### 실제 병원 상황: COVID-19 검사

코로나 검사에서 양성이 나왔다고 해보세요.

**? 정확한 계산** (명확한 전제 조건)

- **유병률(기저율)**: 1%
- **민감도(Sensitivity)**: 95% (실제 감염자 중 양성 비율)
- **특이도(Specificity)**: 95% (비감염자 중 음성 비율)
- **검사 결과**: 양성

### 베이즈 정리 적용

단계 계산 결과

|  |  |  |
| --- | --- | --- |
| **양성예측도 계산** | 0.95×0.01 / (0.95×0.01 + 0.05×0.99) | **16.1%** |

❌ **잘못된 생각**: "민감도가 95%니까 감염 확률도 95%"  
✅ **정확한 해석**: "양성이어도 실제 감염 확률은 16%"

**? 민감도 vs 특이도 vs 정확도**

- **민감도**: 병든 사람을 양성으로 잡아내는 비율
- **특이도**: 건강한 사람을 음성으로 판정하는 비율
- **양성예측도(PPV)**: 양성 판정 중 실제 병든 비율 ← 우리가 알고 싶은 것!

## ? 일상생활 베이즈 사고법

### 1. 온라인 쇼핑 의사결정

```
초기 추정: "이 제품 괜찮을 듯" (호감도 50%)
증거 수집: 
- 별점 4.5/5.0 → 긍정적 신호
- 리뷰 500개+ → 신뢰도 높음  
- 브랜드 인지도 → 추가 신뢰
결과: 호감도 상승 → 구매 결정
```

### 2. 투자 의사결정 과정

베이즈적 접근으로 **단계적 확신도 조정**:

- 초기 분석 → 기본 확신
- 실적 발표 → 확신도 업데이트
- 시장 반응 → 재조정
- 추가 뉴스 → 최종 판단

수치보다는 **업데이트 과정**이 베이즈의 핵심입니다!

## ? 베이즈 vs 일반적 사고

구분 일반적 사고 베이즈 사고

|  |  |  |
| --- | --- | --- |
| **정보 처리** | 첫인상 고착화 | 지속적 업데이트 |
| **불확실성** | 회피하거나 무시 | 확률로 정량화 |
| **반대 증거** | 무시하거나 합리화 | 객관적 반영 |
| **의사결정** | 직감 의존 | 체계적 계산 |

## ⚡ 베이즈 사고의 함정과 대처법

### ? 피해야 할 함정들

1. **기저율 무시**: "검사 정확도만 보고 판단"
2. **확증편향**: "내 생각 뒷받침하는 정보만 수집"
3. **가정 망각**: "전제 조건 바뀌었는데 결론 고수"

### ✅ 올바른 베이즈 사고법

1. **항상 기저율부터** 확인하기
2. **가정을 명시적으로** 표현하기
3. **반대 증거에도** 열린 마음 갖기
4. **확률 범위로** 표현하기 ("90% 확신" 보다 "85-95% 범위")

## ? 마무리: 베이즈 마인드셋의 힘

베이즈 정리는 단순한 수식이 아닙니다. **"내가 틀릴 수 있다"는 겸손함**과 **"새로운 정보로 더 나은 판단을 하겠다"는 의지**가 수학으로 표현된 것입니다.

### ? 베이즈 사고의 3대 원칙

1. **가정을 명확히** 하라 (기저율, 민감도, 특이도)
2. **증거의 무게를** 정량화하라 (우도비)
3. **지속적으로 업데이트** 하라 (새 정보마다 재계산)
