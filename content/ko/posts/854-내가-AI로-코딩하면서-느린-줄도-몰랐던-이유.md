지난주에 제 친구가 이런 말을 하더군요. "요즘 Cursor랑 Claude 쓰니까 개발 속도가 미쳤어. 진짜 2배는 빨라진 것 같아." 저도 그렇게 느꼈거든요. AI가 코드 짜주니까 타이핑하는 시간이 확 줄고, 뭔가 엄청 생산적인 기분이 들잖아요.

그런데 최근 연구 결과를 보고 깜짝 놀랐습니다.

## 느리지만 빠르다고 느끼는 역설

최근 연구에서 경력 개발자들이 Cursor Pro + Claude를 사용했을 때 **실제로는 19% 느려졌다**는 결과가 나왔습니다. 그런데 재미있는 건, 같은 개발자들이 **자신이 20% 빨라졌다고 느꼈다**는 거예요.

어떻게 이런 일이 가능할까요?

구글의 다른 연구에서는 AI를 쓰면 21% 빨라진다는 결과가 나왔거든요. 둘 다 틀린 건 아닙니다. 차이는 **어떤 작업을 측정했느냐**에 있습니다.

제 경험을 돌이켜보니 이해가 되더군요. AI가 코드를 짜주는 속도는 정말 빠릅니다. 타이핑 시간이 확 줄어들죠. 하지만 그 코드를 **읽고, 이해하고, 검증하고, 디버깅하는 시간**은? 오히려 늘어납니다.

AI가 만든 코드는 겉보기엔 그럴듯해 보이지만, 미묘한 버그나 비효율이 숨어있을 때가 많아요. 그걸 찾아내고 고치는 시간까지 합치면 오히려 느려질 수 있다는 거죠.

## 그럼 AI를 언제 써야 할까?

제가 요즘 실천하는 프레임워크는 이렇습니다:

**AI가 도움이 되는 작업:**

- 보일러플레이트 코드 작성 (API 라우트, DB 스키마 등)
- 익숙한 패턴을 반복적으로 구현할 때
- 간단한 유틸리티 함수나 헬퍼 작성

**AI를 조심해야 하는 작업:**

- 복잡한 비즈니스 로직 구현
- 새로운 아키텍처 설계
- 퍼포먼스가 중요한 핵심 로직

**AI를 쓰지 말아야 하는 작업:**

- 내가 정확히 이해하지 못한 코드 작성
- 보안이 중요한 부분
- 레거시 코드베이스의 핵심 로직 수정

현재 데이터를 보면 PR의 13.3%가 봇이 생성한 코드라고 합니다. 이게 좋은 건지 나쁜 건지는 아직 모르겠어요. 하지만 우리가 더 현명하게 써야 한다는 건 분명합니다.

## Claude Sonnet 4.5가 나왔습니다

마침 2025년 9월 29일에 Claude Sonnet 4.5가 출시됐어요. Anthropic은 이걸 "세계 최고의 코딩 모델"이라고 부릅니다. 실제로 써보니 확실히 코드 이해도가 높아진 느낌입니다.

더 흥미로운 건 Claude Code가 정식 출시되면서 GitHub Actions, VS Code, JetBrains 통합이 가능해졌다는 점입니다. 이제 개발 워크플로우 전체에 AI를 자연스럽게 녹일 수 있게 됐어요.

그리고 MCP(Model Context Protocol)가 정말 빠르게 퍼지고 있습니다. 작년에 Anthropic이 공개했을 때만 해도 실험적인 기술이었는데, 지금은 413개 이상의 클라이언트가 지원하고, OpenAI도 올해 3월에 채택했어요. AI 도구들 간의 "USB-C" 같은 표준이 되어가는 중입니다.

새로운 기능들도 많이 추가됐는데요:

- 코드 실행 기능 (바로 결과 확인 가능)
- MCP 커넥터 (외부 도구 연결)
- Files API (문서 처리 개선)
- 1시간 캐싱 (반복 작업 최적화)

## 이번 주에 해볼 만한 것들

1. **자신의 AI 사용 패턴 점검하기** - 이번 주에 AI로 작성한 코드 중 몇 개나 수정했나요? 시간을 재보세요. 생각보다 느릴 수도 있습니다.
2. **작업 분류해보기** - 어떤 작업에서 AI가 정말 도움이 됐는지, 어떤 작업에서 오히려 방해가 됐는지 메모해보세요. 자신만의 패턴을 찾을 수 있습니다.
3. **Claude Sonnet 4.5 시도해보기** - 기존에 쓰던 AI 도구와 비교해보세요. 특히 복잡한 코드 리뷰나 리팩토링 작업에서 차이가 느껴질 겁니다.

## 마치며

AI 도구는 분명 강력합니다. 하지만 **빠르다고 느끼는 것**과 **실제로 빠른 것**은 다릅니다.

제 생각에 AI는 자전거 같은 도구예요. 내리막길에서는 정말 빠르지만, 오르막길에서는 오히려 무게가 될 수 있죠. 어디가 내리막이고 어디가 오르막인지 아는 게 중요합니다.

이번 주에는 AI를 쓰면서 한 번쯤 멈춰서 생각해보면 어떨까요? "지금 이 작업에 AI가 정말 도움이 되고 있나?"

그 질문에 대한 답을 찾다 보면, AI를 더 현명하게 쓸 수 있을 거라 믿습니다.

AI를 좋아하지 않으시더라도, Claude Sonnet 4.5는 꼭 한 번 써보시길 바라며.
