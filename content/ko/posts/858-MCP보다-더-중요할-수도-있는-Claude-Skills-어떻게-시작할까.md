Claude Skills가 출시됐다는 소식을 듣고 바로 공식 문서를 찾아봤어요. 읽고 나서 든 생각? "좋아 보이는데... 근데 실제로 어떻게 쓰라는 거지?"

여러분도 비슷한 경험 있으신가요? 새로운 AI 도구가 나올 때마다 "혁신적이다", "게임 체인저다" 같은 말만 잔뜩 보고, 정작 "내일 당장 뭘 해볼 수 있나?"에 대한 답은 없는 경우요.

그래서 지난 2일간 직접 써보고, 다른 사람들 반응도 살펴봤어요. 공유할 가치가 있는 것들을 발견했습니다.

## Claude Skills가 뭔가요?

일단 복잡한 설명은 건너뛰고, 가장 단순하게 설명하면:

**폴더 하나 + 마크다운 파일 몇 개 = Skills**

정말 이게 답니다. MCP(Model Context Protocol)처럼 수만 개의 토큰을 처음부터 로드할 필요 없이, Skills는 시작할 때 수십 개 토큰만 사용해요. 필요할 때만 더 불러옵니다.

구조는 이렇게 생김:

- 마크다운 파일: 지시사항과 설명
- YAML 파일: 설정
- 선택적으로: 스크립트나 추가 도구

Claude 앱에서도 되고, Claude Code에서도 되고, API에서도 됩니다.

## 왜 중요한가?

Simon Willison(유명 개발자)이 이렇게 말했어요: "MCP보다 더 큰 일이 될지도 모른다."

처음엔 과장 같았는데, 써보니 이해가 갔어요.

**실제 사례:**

- 저같은 경우: 반복적인 코드 리뷰 작업을 Skill로 만들어서 매번 같은 프롬프트 안 써도 됨

핵심은 **단순함**이에요. MCP는 강력하지만 설정이 복잡해요. Skills는 마크다운 파일 몇 개면 끝입니다.

## 지금 당장 시작하는 법

### 1단계: 반복하는 작업 하나 고르기 (5분)

주간 보고서 쓰기, 코드 리뷰, 회의록 정리, 뉴스레터 아이디어 정리... 무엇이든 괜찮아요.

### 2단계: 간단한 Skills 만들기 (10분)

폴더 하나 만들고, `skill.md` 파일 작성:

```
# 주간 보고서 작성 도우미

당신은 주간 업무를 정리해서 간결한 보고서로 만드는 전문가입니다.

## 작업 방식
1. 지난주 작업 내용 듣기
2. 핵심 성과 3가지 추출
3. 다음주 계획 정리
4. 깔끔한 보고서 형식으로 작성
```

이게 다예요.

### 3단계: Claude에 연결하고 써보기 (5분)

Claude 앱이나 Claude Code에서 Skills 폴더 지정하면 바로 사용 가능합니다.

## 알아둘 점

**좋은 점:**

- 설정이 정말 쉬움
- 필요한 만큼만 컨텍스트 사용
- 다양한 환경에서 작동
- 버전 관리 가능 (그냥 파일이니까)

**주의할 점:**

- 아직 초기 단계 (출시 2일 차)
- 보안: Skills가 어떤 권한을 요청하는지 확인 필요
- 다른 사람이 만든 Skill 쓸 때는 코드 한번 읽어보기

특히 보안은 중요해요. Skill은 파일 접근이나 명령 실행 권한을 가질 수 있어서, 신뢰할 수 있는 출처인지 확인하는 게 좋습니다.

## 왜 지금이 좋은 타이밍인가?

솔직히 말하면, 지금은 실용적인 가이드가 거의 없어요. 공식 문서와 개념적인 설명만 있고, "이렇게 써봤더니 좋더라" 같은 실전 경험담은 아직 부족합니다.

**즉, 지금 시작하면:**

- 초기 커뮤니티에 참여할 수 있음
- 자신만의 유용한 Skills를 먼저 만들 수 있음
- 시행착오를 겪더라도 남들도 다 비슷한 단계

저도 계속 실험 중이에요. 실패도 하고, 다시 만들기도 하고요. 그게 정상입니다.

## 이번 주에 해볼 만한 것들

1. **반복 작업 하나 찾기**: 매주/매일 하는 것 중 가장 지루한 거
2. **첫 Skill 만들기**: 완벽할 필요 없음, 10분 투자
3. **써보고 개선하기**: 한두 번 써보면 뭘 고쳐야 할지 보임
4. **다른 사람들 경험 찾아보기**: Twitter, Reddit에서 #ClaudeSkills 검색

완벽한 Skill을 만들려고 하지 마세요. 일단 하나 만들어서 써보는 게 중요합니다. 저도 첫 번째는 형편없었어요. 세 번째쯤 되니까 쓸 만해졌습니다.
