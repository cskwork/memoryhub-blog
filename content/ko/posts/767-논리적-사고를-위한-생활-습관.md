**10 가지 원칙**

1. 정의되지 않은 용어로는 논증할 수 없다.
2. 주장은 주장, 증거는 증거—둘을 분리해 적는다.
3. 상관관계는 인과가 아니다; 대안 설명부터 열거한다.
4. 반례 하나면 일반화는 무너진다.
5. 가능한 설명 중 가장 단순한 것부터 검토한다.
6. 숫자 없이 강한 주장은 약하다.
7. 데이터·가정·추론·결론을 구분해 기록한다.
8. 예외 조건과 전제의 범위를 명시한다.
9. 틀렸을 때의 비용을 계산해 결론의 실용성을 점검한다.
10. 나는 틀릴 수 있다; 반대 증거를 먼저 찾는다.

작게 실천하는 법 (추천 3분 루틴) : 기사/과제 하나를 고르고 위 10문장으로 체크하며 2~3 줄로 결론을 다시 써보기.

**간단 템플릿 3개:**

- 모순법: “만약 P라면 Q다. Q가 아니다. 그러므로 P가 아니다.”
- 귀무-대립 가설: “H0와 H1을 세우고, 데이터로 H0를 기각할 수 있는가만 본다.”
- 원인-효과 그래프: “원인 후보 → 중간 변수 → 결과”로 화살표 그려보기.

|  |  |  |  |
| --- | --- | --- | --- |
| 1 | **정의되지 않은 용어로는 논증할 수 없다** | 핵심 단어를 먼저 뜻부터 딱 정해라. | “효율적 설계” → 공사기간(일), ㎡당 비용(원)처럼 수치로 정의. |
| 2 | **주장은 주장, 증거는 증거—분리** | 느낌(주장)과 사실(증거)을 같은 줄에 놓지 마라. | “이 자재가 친환경(주장). 탄소배출 LCA가 25% 낮음(증거).” |
| 3 | **상관관계≠인과; 대안 설명부터** | 같이 변한다고 원인이 되는 게 아니다. 다른 이유부터 찾아봐라. | 아이스크림 판매↑와 익사↑ → “더운 날씨”라는 제3의 변수. |
| 4 | **반례 하나면 일반화는 무너진다** | “항상/모두/절대”엔 예외 1개면 끝. | “모든 학생은 밤에 더 집중한다” → 오전형 학생 한 명으로 반박. |
| 5 | **가능한 설명 중 가장 단순한 것부터** | 복잡한 가설 전에 쉬운 원인부터 체크. | 앱이 느리다 → 서버 상태/네트워크 먼저, 희귀 OS 버그는 나중. |
| 6 | **숫자 없이 강한 주장은 약하다** | 수치·단위 없으면 신뢰도 0에 수렴. | “매우 개선” 대신 “처리시간 3.2초→1.9초(-41%).” |
| 7 | **데이터·가정·추론·결론을 구분** | ‘봤다–가정했다–그래서 생각한다–따라서 한다’를 따로 적어라. | 데이터: 결석 12%↑ / 가정: 감기 유행 / 추론: 환기 부족 / 결론: 환기 횟수 2배. |
| 8 | **예외와 전제의 범위를 명시** | “언제·누구·어디에 한해서”를 밝혀라. | “효과 있음(20대 남성, 주 3회, 8주, 고강도 기준).” |
| 9 | **틀렸을 때의 비용을 계산** | 오판 비용이 큰 쪽부터 보수적으로 의사결정. | 가스누출 경보: 오경보 비용 < 미경보 재난 → 민감도 높게. |
| 10 | **나는 틀릴 수 있다; 반대 증거부터** | 내 결론을 깨뜨릴 수 있는 증거를 먼저 찾아라. | “A 설계가 싸다”라면 숨은 유지관리비·수명 단축 자료부터 확인. |

### 2분 실천 루틴

1. 문제 한 줄 요약 → 2) 핵심 용어 정의(#1) → 3) 주장/증거 분리(#2,6) → 4) 대안 설명·예외·전제(#3,#8) → 5) DAGC 기록(#7) → 6) 오판비용 체크(#9) → 7) 반대 증거 검색(#10) → 8) 최종 결론과 근거 수치 1줄.

## 미니 케이스: “자재 A가 친환경이라 바꿔야 한다”

- **정의(#1)**: 친환경 = LCA 기준 전 주기 CO₂e 20%↓ 이상
- **주장/증거 분리(#2,#6)**: 주장: 교체 필요 / 증거: A가 B 대비 CO₂e 24%↓(㎏CO₂e/㎡)
- **상관·인과(#3)**: “SNS 인기↑”는 이유가 아님. 실측 LCA가 원인 자료
- **반례(#4)**: 내구성↓라면 교체 주기↑ → 오히려 CO₂e↑ 가능
- **단순 설명(#5)**: 현 자재 시공오류/폐기 관리가 문제일 수도
- **D→A→R→C(#7)**:
  - D: A의 LCA -24%, 단가 +8%
  - A: 유지관리 주기 동일
  - R: 10년 TCO는 +1.5% 내에서 CO₂e 18%↓
  - C: 공용부만 A로 시범 적용(1개 동) 후 6개월 재평가
- **범위(#8)**: 기후대 II, 실내 마감, 유지보수 10년 기준
- **오판비용(#9)**: 잘못 교체 시 비용↑·성능↓ → 소규모 파일럿 먼저
- **반대 증거(#10)**: A의 VOC↑ 가능성 → 실측 시험 선행

**결론:** “공용부 1동 파일럿, VOC·내구성 통과 시 전면 확대(10년 CO₂e 18%↓, TCO +≤1.5%).”

## 바로 쓰는 템플릿 3종

### 1) D→A→R→C 워크시트

```
[문제 한 줄]
[정의한 핵심 용어]

D(데이터):
A(가정):
R(추론):
C(결론):

[예외/전제 범위]
[오판비용(큰→보수적으로)]
[반대 증거/반례 체크]
```

### 2) 모순법(간단 논증)

```
만약 P라면 Q다.
그런데 Q가 아니다.
그러므로 P가 아니다.
```

### 3) 원인-효과 미니 다이어그램

```
원인 후보1 → 중간변수 → 결과
원인 후보2 → (측정지표)
※ 간단히 화살표 2~3개만
```

## 한 장 체크리스트(복붙용)

- 핵심 용어 정의했나?(수치·단위 포함)
- 주장/증거 분리했나? 숫자 붙였나?
- 상관관계와 인과를 구분했나? 대안 설명을 먼저 찾았나?
- 일반화에 반례가 있는가?
- 단순한 설명부터 배제했나?
- D→A→R→C로 기록했나?
- 예외·전제 범위를 썼나?
- 틀렸을 때 비용을 계산했나?
- 반대 증거를 먼저 확인했나?
- 최종 결론을 **1문장+숫자**로 요약했나?
